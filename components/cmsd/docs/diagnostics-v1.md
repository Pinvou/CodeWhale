# 无LLM的只读实例诊断

`cmsd --diagnose`是客户端命令：按最终配置连接本机Unix socket，顺序读取固定的
`/v1/device`、`/v1/status`、`/v1/control/status`、`/v1/remote/status`，向stdout输出
`megacube-cmsd-diagnostic-v1` JSON。与`--check-config`分开：后者不连接实例，只验证
配置；诊断读取当前实例事实，但不验证模型推理、完整产品功能或物理多机。

```bash
CMSD_CONFIG=/absolute/private/cmsd.toml /absolute/cmsd --diagnose
```

配置仍遵循既有文件/环境覆盖顺序；没有指定配置时使用当前账号默认值。必须核实它与
准备检查的实例一致；不能通过修改socket权限为0666解决访问问题。system模式的诊断
只检查服务端root UID，不要求提供模型执行账号；正常启动仍要求显式CMSD_RUN_USER。
user模式只接受当前UID。每次连接核实OS提供的PID/UID，四次读取要求同一服务PID；
这不是unit/二进制绑定或设备签名验证，报告明确这两项均未验证。

## 返回与解释

| 退出码 | 含义 |
|---|---|
| 0 | 固定读取可用，无本次已知需处理项；不是模型可用性或完整功能验收 |
| 2 | 参数或配置错误，尚未连接实例 |
| 3 | 核心事实可读，但网关监听、维护/退化模型、计划权威、远端配置或旧版可选接口需要核查 |
| 4 | 核心事实未核实、拒绝访问，或读取期间PID/设备/boot发生变化 |

各项分别为available、degraded、not_configured、unsupported、unavailable；读取期间
身份变化时已有事实全部失效，标为unconfirmed，避免把两代实例的计数拼成同一快照。
各次GET本身仍是分开的时刻，不是跨四个接口的原子快照。

未配置远端是not_configured，不要求安装全部套件；旧版缺少可选接口是unsupported，
不是已证明“没有计划/远端设备”；可选接口明确不支持本身不使健康本机服务降级。注册模型、托管、仅观察与管理权未知分别统计，
正在运行只表示daemon报告的进程状态。网关ready只代表其监听，不证明上游健康或推理。
诊断不尝试推理请求，也不把实际模型的思考字段当最终文本。设备身份范围原样按安全
标识符投影，不把local-state-only提升为远程可信身份。

本单机服务不提供计划与远程授权接口。诊断客户端将这些可选接口缺失明确报告为 unsupported，也可只读观察旧完整组件给出的状态；这不表示本组件实现了配对或授权功能。原始错误、模型日志、CA、私有能力和完整模型路径不写入报告。

## 有界与恢复

只读四个固定GET端点，每项至多两读，不发POST或私有能力头；不直接打开设备状态、身份或授权文件，不
创建状态/锁/监听，不运行systemctl、Docker、Shell或旧脚本。既有服务在GET中执行
自身事实检查，发现权威漂移时仍按既有规则锁定；诊断不会替其修复或清除锁定。

每个端点共享一秒连接/发送/接收期限，含满socket队列和滴流；响应体最大256KiB，
超量明确未核实，不截断后当空结果。HTTP头仍有既有64KiB上限，JSON复用拒绝重复键、
过深结构的解析器。不查询较慢网络CLI、引擎扫描、日志、逐模型健康或大任务列表。
四秒是四份顺序IO预算，调度/解析仍有开销，不承诺硬实时上界。仅503或status中的
身份暂未核实可等20毫秒再读一次，仍使用原一秒剩余期限；返回attempts及首次失败码。
不重复畸形JSON、拒绝访问或已锁定权威；任何重读仍只观察，持续失败不回退旧事实。

发生错误先核实当前配置与精确实例，在Pinvou“侧栏设备管理（普通设备为运行状态）→MegaCube→Cube Manage Software”或该unit的日志查看
救援入口。保留原任务/操作ID及当前身份、撤销、授权、台账和冷档案，修复匹配配置后
刷新。已经锁定的权威须恢复当前匹配材料并重启该测试/目标实例重新载入；不要把旧
授权快照覆盖活动服务。命令不会自动恢复、升级、删除、换实例或切换写后端。

本批不改变状态格式和既有API。软件回退到不支持该参数的旧制品会退出参数错误，
不能将其作为启动失败或改走旧脚本的依据。可继续使用旧版对应的只读socket/日志入口。
