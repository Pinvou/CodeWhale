# 原生模型档位内存准入

历史开发观测说明，长上下文档位的实际系统可用内存差可能高于权重加固定运行开销的估算。该差值受其他进程影响，不能当作隔离峰值或当前 PR 制品的 GPU 验收；具体机器观测保留在对应本地验收记录，产品合同以当前卡片声明和统一准入函数为准。

原生标准卡 common.sh 可声明字面量 `CMSD_RESERVED_GIB="48"`，不执行脚本。需求量取此预留、有效历史实测、权重加运行时下限的最大值，再另留 max(8 GiB, 总内存8%)。较小/缺失/无效的历史测量不会缩小声明预留；较大实测继续抬高准入。声明值非有限数、零、负数或非数字时明确拒绝预算，不静默退回较小估算；未声明旧卡保留原估算/实测语义。

例如卡片声明48 GiB运行需求预留时，仍须另加按当前主机总内存计算的系统边际，不使用某次机器观测中的固定余量。这是对应模型/引擎/上下文档位的保守准入下限，不是所有模型、长输入或多模态工作负载的峰值保证；变更档位须重新标定。/v1/capacity、显式enable、switch预检、自动恢复和降级复核使用同一需求量函数，不能展示足够后在执行时改用另一较小口径。

二进制 --component-info 新增 native_profile_budget:1。新配置写入 require_native_profile_budget="v1" 作为兼容要求；旧严格解析器会在打开状态前拒绝，避免软件回退后忽略卡片预留。新Pinvou在停止现有服务前探测该能力。此配置不添加管理权、不迁移单位，也不改变普通旧卡的预算来源。

实验产物仅登记仍为只读；显式启用和恢复意图的权限语义不变。旧受控状态不通过删除或回填备份来降低预算，模型商店仍是标准卡安装业务的唯一执行者。

单元回归覆盖首次预留、低于预留的测量不降档、较大实测升档、低内存拒绝、未声明旧卡兼容、非数字/NaN/inf/零/负值失败。本批使用隔离夹具验证上述逻辑；实际GPU推理、峰值预算、整机重启及长期负载需要对当前制品另行验收，不以历史开发记录替代。
