# documents (compatibility stub)

This stub exists so the legacy name `docx` keeps resolving. It contains no
workflow of its own.

If the `docx` skill is installed and enabled, load_skill("docx") returns
it directly. If loading `docx` returns this stub again, `docx` is not
installed or is disabled — tell the user, and continue with generic guidance
for this file type instead of retrying.
