# Token 高风险审批的近期认证

ADM-64 的模型生命周期变更、模型目录回滚和凭据撤销三类审批，
由 Account 仓储在新建、编辑、提交申请及批准、驳回决定的真实写入口
校验 IdP Principal 中的认证时间。v1、v2 HTTP 入口共用这些判断，
拒绝时沿用 `RECENT_AUTHENTICATION_REQUIRED`，不接受请求体自报时间。

认证窗口复用既有十五分钟规则和一分钟未来时钟容差。
申请在领域快照调用前及写入前检查，批准在 proof 获取前及最终 writer
授权后重新检查，不能只依赖页面提示或先前的预检结果。

新门禁仅适用于上述三类命令；Token 五分钟领域预检及其它 Billing
命令的既有近期认证要求保持原样。撤回仍可安全收口。
精确的已持久化申请回执按原规则只读重放，继续执行原来的权限、
可见性、幂等事实、控制门和适用激活检查，不重新派发领域效果。

认证年龄检查不等同于数据库锁等待后的全部授权、申请和 proof 时效
围栏；后者是另行审核的边界，不能据此宣称整个审批链验收通过。
