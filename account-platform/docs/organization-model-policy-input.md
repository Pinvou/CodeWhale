# 组织模型政策输入错误

已认证且具有目标组织 `org.models.manage` 权限的政策写入，若 mode、reason、幂等键、模型 ID 集合或 expected_version 不符合原有输入约束，返回 `400 INVALID_REQUEST`。身份、当前组织权限和可信授权版本检查保持失败关闭；权限不足仍返回 `403 TOKEN_FORBIDDEN`，不会用输入错误掩盖授权拒绝。

输入校验发生在仓储开启事务之前，不写政策、审计或幂等回执。拒绝后仍可提交合法新请求、按原键读取旧版本回执。模式规范化、空模型集合、金额和资金行为、CAS、摘要算法及已存历史均不改变。模型确实不可用仍为原 `422 MODEL_UNAVAILABLE`，版本冲突仍为 `409 MODEL_POLICY_VERSION_CONFLICT`；存储错误保持原内部错误，不回传原始依赖错误。

真实 HTTP 回归经过已注册 Handler、认证中间件和当前 Account 授权客户端，输入分类调用真实仓储的前置校验；授权服务使用受控端点。真实 PostgreSQL 回归使用原公开 Token 迁移和非所有者运行角色，核对无写入、下一次合法写入及旧回执重放；不代表外部身份供应或模型提供方验收。
