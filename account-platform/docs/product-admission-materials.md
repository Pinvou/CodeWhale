# 商品准入原件保管

本前置能力只保管商品准入的一份原始 PNG、JPEG 或 PDF。它不会签发正式商品准入，不新增强退、通用附件、OCR 或自动渠道验真。人工核验与正式准入由独立后继 PR 提供。

## 启用边界

`BILLING_PRODUCT_ADMISSION_MATERIALS_ENABLED` 默认 `false`；关闭时不注册原件入口，不影响既有个人余额服务。启用必须显式提供下列配置，任一配置不合法即拒绝启动该配置：

| 配置 | 用途 |
| --- | --- |
| `BILLING_PRODUCT_ADMISSION_VALIDATOR_SOCKET` | 独立 Linux 校验器的绝对 Unix socket 路径 |
| `BILLING_PRODUCT_ADMISSION_VALIDATOR_UID` | 非零、与 Billing 隔离的校验器 UID |
| `BILLING_PRODUCT_ADMISSION_KEY_ID` | 专用 Transit 密钥名称 |
| `BILLING_PRODUCT_ADMISSION_TRANSIT_URL` | Transit 地址；正式环境要求 HTTPS |
| `BILLING_PRODUCT_ADMISSION_TRANSIT_TOKEN_FILE` | 专用、可轮换、绝对路径凭据文件 |
| `BILLING_PRODUCT_ADMISSION_TRANSIT_CA_FILE` | 私有 CA 文件；公共 CA 场景可留空 |

复用共享 Transit 客户端与独立凭证校验器，不接受本地明文密钥、共享 Token 网关身份或验证失败后的降级存储。部署方只给此工作负载所需密钥的加解密权限，并保留历史密钥解密能力；不得删除仍有留存原件依赖的密钥。凭据、CA 和 socket 由受控编排平台挂载，不写入商品资料或前端。

校验器接受 1 byte–10 MiB 的原始文件、最多 4000 万像素的静态图片，拒绝 APNG、无法解析、需要密码或检查有警告的 PDF。可用空密码直接读取且通过完整检查的 PDF 不因加密标记而被拒绝。校验成功仅证明格式可读取，不证明渠道真实性。

在 Linux 真实 UID、socket 重启、cgroup/OOM 隔离、PDF 容器及实际资源预算完成部署验收之前保持关闭。Windows 的受控 HTTP、数据库与加密测试不能替代这些验收。本变更不自动修改 Compose/Helm 或投递任何生产凭据。

## 访问与幂等

所有入口要求当前 `platform.products.publish` 权限和 15 分钟内重新认证。原件返回前再次查询当前权限，并确认原件未被清理；读取成功记录审计。下载只作附件返回，设置 `no-store` 与 `nosniff`。上传与原件下载上限为 10 MiB，Portal 其它财务请求仍为 4 MiB。

上传必须提供 `Idempotency-Key`、商品版本和预期准入到期时间。服务端计算原始字节摘要；同一操作者的同一 key 只能重试相同商品、版本、文件事实和到期时间。网络结果不明时保留原 key，可先查询操作者专属回执；404 不证明从未提交。回执不含原件、密文或密钥。

上传不是核验投票。原件只允许绑定一次准入申请；商品版本或到期时间不匹配时拒绝绑定。

## 留存、保留与清理

按已确认的 A 方案，原件在准入有效期间保留，在到期、撤销或拒绝后继续保留三个日历年。未绑定或待核验原件使用上传时明确的预期到期时间作为终点，不另设无限待处理状态。较早终止时按较早终点计时，使用 UTC 日历年计算。

具体原件可设置法律保留：必须有原因及复查时间；复查时间到达不会自动解除，必须由有权限且近期认证的人员明确释放，并记录审计。行政版本独立于不可变的加密绑定版本。

现有商品准入到期任务每分钟以有界批次清理满足留存期限、且没有法律保留的原件密文及封装数据密钥；数据库触发器再次阻止提前删除。最小摘要、标识、清理时间及审计墓碑不等同于原始凭证。本能力不改变其它订单、账本或审计留存政策，也不承诺这些墓碑永久保存。

部署验收必须监测到期但尚未清理的记录、清理任务失败及法律保留复查时间，并证明在现有 30 天清理窗口内清除可恢复副本，包括备份、快照、归档和副本。数据库行删除不能证明存储介质即时抹除或备份已销毁；无法证明时不得声称完成留存合规验收。

升级使用公开迁移包装器及独立 schema owner/runtime 身份。新增 `900037` 保留精确迁移身份，不重编号或改写既有迁移。回滚不得以删除仍在留存期内的原件为代价。
