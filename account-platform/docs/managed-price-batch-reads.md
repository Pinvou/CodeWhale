# 管理价格的批量读取

总价格列表及指定价格空间列表先按原顺序选取最多 200 个分页 ID，再在同一个 RepeatableRead 事务中批量读取价格/namespace ETag 和全部单位配置。非空正常总列表使用 3 次 SELECT，价格空间列表使用 4 次；空页保持原提前返回行为。该计数是 SQL 执行次数，不是生产延迟承诺。

原 `created_at,id` 顺序、游标、limit+1 延续判断、12 个价格字段、单位 ID 顺序、显式零值/继承的 nil 形态、存储与当前 ETag、派生状态及 HTTP DTO 保持。并发写入在本次页的旧快照之外完成时，整页仍使用同一旧快照，后续读取可见已提交事实。

总列表缺少 namespace 仍返回原错误，不使用默认 ETag 或静默省略价格。未建立的指定空间仍返回 ETag 1 和空列表。查询、扫描、rows 和取消错误沿原路径传播。单项读取、价格写入的 FOR UPDATE、namespace 锁和命令回执没有改变；无 schema 或索引迁移。

回归使用公开迁移、受限 Billing 角色及真实草稿生产者，按 1/100/200 条测量 SQL 次数并逐字段对照原单项读。channel barrier 固定真实并发写入时序；自有数据库的表级 SELECT 故障用于验证错误身份和后续恢复。空单位及缺 namespace 案例明确是受损历史输入，不是正常草稿创建结果。
