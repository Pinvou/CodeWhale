# Portal 可选语言偏好

个人 Portal、管理 Portal 和桌面会话交接页不能依赖浏览器允许本地
语言偏好存储。获取 `localStorage`、读取或写入偏好被拒绝时，仅放弃
本次持久化；页面仍初始化，语言切换仍更新内存和既有管理端通知。

个人页保留 URL 的有效 `locale`、已存语言、浏览器语言、中文的优先级。
URL 中的 `locale` 按原规则消费，写入偏好失败也不保留该参数。
管理页沿用独立的偏好键和浏览器语言规则。会话交接页仍先清理 URL
票据，再执行唯一的交接请求；偏好失败不触发重试或替代认证流程。

容错仅限可选语言偏好。注册赠送、审批、导出等业务恢复凭据的
`sessionStorage` 安全检查保持原有失败关闭行为；URL 清理、界面状态
更新等其它异常也不会被语言存储辅助函数吞掉。

`portal-language-storage.test.mjs` 在 Node 合同门禁执行真实入口初始化、
切换回调和交接流程，覆盖不可用存储及三语正向行为。浏览器验证使用
独立临时配置和受控 API，不能代替真实 IdP 或部署验收。
