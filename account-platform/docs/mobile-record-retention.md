# 移动认证记录保留

经本轮明确确认，验证码挑战（图片按请求生成、不存储）保留24小时，短信挑战、发送与验证记录保留90天。清理每小时执行；每表每轮最多500行，单轮30秒超时，失败以静态错误码记录并在下轮重试。保留期限从挑战updated_at或发送/验证occurred_at起算，持续活动会延长保留。

仅删除已过期挑战。未过期验证码/短信、仍有投递租约的短信、不确定投递、注册操作关联、注册/资料变更/密码重置引用全部保留。发送与验证记录只清理超过90天且不再关联任何短信挑战的行；旧挑战删除由既有外键置空历史计数引用，不改变业务操作。任意仍有业务引用的记录可超过保留期，后续需通过该业务的独立归档策略处理，不在本轮清理业务历史。

清理使用数据库时间、事务及SKIP LOCKED，避免占用正在处理的行；外键保护并发建立的业务引用。清理失败整轮回滚，绝不吞错或输出号码、验证码、provider原始异常。多实例可安全重复执行。前向迁移000090只增加清理索引，不修改已应用SQL和校验和。

公共入口限流桶具有独立短TTL且无业务引用，其清理策略见 public-mobile-admission.md，不能替代90天短信保留策略。
