# 协议与公式草稿的版本输入

管理页创建草稿前验证既有版本事实：

| 字段 | 范围 |
|---|---|
| `expected_protocol_head_version` | 大于等于 0；0 表示没有已有协议版本 |
| `expected_formula_head_version` | 大于等于 0；0 表示没有已有公式版本 |
| `expected_protocol_version` | 大于等于 1 |

前端只发送 JavaScript 可精确表示的安全整数。保留合法整数及整数字符串输入，保留省略 head 时的原有默认 0；不接受非有限数、小数、超出安全精度、负值或不符合上述范围的值，也不把无效版本截断为 0。非法输入显示中、英、日对应提示，要求刷新数据后重试，不生成命令或提交版本为 null 的请求。

该检查使用现有草稿构造器和对话框错误出口。服务端版本围栏、认证授权、摘要、幂等键与历史回执保持原样，仍由权威服务校验实际版本。未知执行结果的原键恢复及字段锁定不受影响；本项不表示对任意损坏服务端数据或财务流程的完整验收。
