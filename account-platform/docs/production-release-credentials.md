密码安装及到期任务实际启用均经独立现场验收通过，C4C3b2a 完成；b2b 数据库访问接线尚未执行。

本项不启动业务、不激活治理、不重开旧 gateway，也不重建正式数据库或身份设施。

## 需求与身份边界

1. 沿用已经准备的两个准确 release-scoped Token 角色，各自配置独立随机数据库密码，保持 NOLOGIN。
   Credential 只使用 credential 角色；Gateway 与同代 Token Relay 使用 gateway 角色。
   两种密码不得互换，不授予 schema、策略或治理写入权限。
2. 新建 `account_policy_release_20260909`，仅用于原生 Account 策略检查与 Token 治理工具的跨库策略锁。
   为非超级用户、NOINHERIT、不能创建角色/库、不能复制或绕过 RLS、无角色成员关系的 NOLOGIN 角色。
   只授予目标 Account 库 CONNECT、public schema USAGE、approval_command_policies 表 SELECT/UPDATE。
   PostgreSQL 的 SHARE 锁需要实际 UPDATE 权限，不能称该身份为“纯只读”；它不得成为业务运行身份。
   审批策略行集必须保持原摘要，受控工具只检查和持锁，不提交策略 UPDATE。
3. 三种新密码分别由安全随机源生成 32 字节并编码为 64 位十六进制，不能沿用测试值或其他角色密码。
   Token 运行密码初始有效期为生成时刻起 90 天，Account 运维密码为受控安装时刻起 24 小时。
   角色有效期不等于自动中断现有连接，也不代替 NOLOGIN 和运维工具退场。
4. 延用已有恢复公钥与 age 加密保管方案，不索取口令、私钥或初始 root。原身份保管确认不冒充本批新秘密
   的离线确认。新加密包下载到仅当前保管人和 SYSTEM 可读的独立本机目录；负责人确认离线保存后才设置
   数据库密码。生成/下载/安装均保留各自回执，不因重试生成替代密码或覆盖半完成状态。
5. 为有限有效期建立每日本机到期检查，只消费安装时从真实 pg_roles 回读并以摘要绑定的无秘密到期清单，
   不连接数据库、不读取密码、不访问 Docker Socket，也不创建查询身份。这是已登记到期值巡检，不能证明
   数据库当前 VALID UNTIL 未被随后更改；每次受控轮换必须更新并重新核验清单及摘要绑定。
   运行身份剩余大于 14 天为 OK/exit 0，14 天以内为 WARNING/exit 1，7 天以内（含）为 CRITICAL/exit 2，
   过期为 EXPIRED/exit 3；缺失、摘要不符、非法时间或结构为 INVALID/exit 4，均不得输出成功状态。
   运维身份在安装窗口结束时必须 NOLOGIN，完成后
   不把它的自然到期误报为运行服务故障。告警落在受控状态文件和 systemd 失败状态中，尚无外部通知渠道，
   交接明确由负责人巡检；不能声称已短信、邮件或异机告警。

## 分任务实施

### C4C3b2a：生成与保管，随后受控安装

- 核验正式集群、b1 清理回执、两个候选 NOLOGIN/无密码/准确成员关系、Account 运维角色不存在。
  验证已有 age 可执行文件与恢复公钥摘要；只创建本批排他私有目录，不修改已有材料和备份。
- 生成三项新秘密，逐项加密为独立 age 包，写入不含密码的清单、有效期及加密包字节摘要。
  运行身份记录生成后 90 天的准确到期值；Account 运维生成清单只记录安装后 24 小时 TTL，绝对到期值
  在实际安装时确定，并由真实数据库回读写入安装回执和无秘密消费清单，不以生成时间代替安装时间。
  服务器明文只存 root 0600、父目录 0700 的受控材料区；本机只下载密文和公开元数据。
  输出只含固定状态与保管目录，不回显密码、SCRAM verifier 或明文包内容。加密文件生成/摘要核验不等于
  保管人已经实际解密验证恢复，须据实区分。
- 独立复核后交付新增离线包。缺少本批离线确认时，可继续无秘密代码/配置准备，不执行密码安装。
- 确认后新建加密备份检查点，在准确本地 DBA 维护事务内核验原角色/Account 策略/Token 治理基线及零会话，
  仅设置两个候选的 SCRAM 密码与有限有效期、新建上述 Account 运维身份及准确权限。全部仍 NOLOGIN。
  不输出密码/verifier，不把含秘密 SQL 放到 argv、可读日志或仓库；会话错误和语句日志必须经检查禁止泄漏。
  结果未知先只读查角色/密码匹配证明和原操作回执，不盲目再执行。
  日志检查覆盖 postgres、Token、Account 三库，禁止语句/耗时采样、错误语句和三项 debug_print_* 解析日志；
  实际安装会话使用安全启动参数，并在任何凭据 DDL 前独立回读验证，失败立即中止后续发送。
  密码在受限进程内派生 SCRAM verifier，SQL 经 stdin 发送 verifier 而非明文密码，不把它保存成 SQL 文件。
  跨库操作明确拆成两个有独立意图/结果回执的事务：先在 Token 库维护锁内设置两候选密码并创建带密码的
  NOLOGIN Account 运维角色；再在 Account 库 SHARE NOWAIT 锁内核验原策略摘要并授予其四项准确权限。
  角色属于集群级而表/schema 授权属于数据库级，不宣称两事务跨库原子提交。第二阶段失败时，新角色仍
  NOLOGIN，保留第一阶段结果并按原回执恢复，不删除角色或重设密码。前后核验全局角色/成员关系与其他角色
  密码摘要不变，Account 有效 ACL 除新增 CONNECT、USAGE、SELECT、UPDATE 四项外不变。
- 逐服务独立只读消费目录投递 pgpass；Gateway、Credential、Relay 和运维工具不挂载包含其他身份的父目录。
  设置目标 UID/GID 65532、文件 0600/目录 0700，使用密码无关的 verify-full DSN 和单独公开 CA。
  验证存储为 SCRAM、准确到期时间；在受限进程内以原密码及存储 SCRAM 参数重新计算 StoredKey/ServerKey
  并恒时比较，验证匹配但不打印任何存储值、派生密钥或密码。这不是实际成功登录证明，三个身份仍 NOLOGIN。
- 实现并验证到期检查正/负例及实际 timer、输出不含秘密。核验完整数据/治理/其他角色无变化，做操作后备份，
  独立审核通过后提交。本项完成仍不代表能够登录或业务已启动。

### C4C3b2b：准确 HBA 与原生授权检查

- 先检查真实 HBA 来源文件、容器内绑定、文件 inode/hash/权限及当前有序规则，固定本批前后版本。
  仅新增目标 Token 库的两个准确角色，以及目标 Account 库的运维角色规则；新增规则限定真实 data network
  IPv4 子网、hostssl 与 scram-sha-256，插在最终拒绝规则之前。其他既有规则、端口和网络不变。
  现有初始化规则使用 all 地址不代表新规则可继续放宽；本批不擅自重写其他域的既有规则。
- 现有 HBA 是单文件 bind mount：不能原子替换宿主文件后误认为容器会读到新 inode。写入采用准确原 inode
  的有界受控更新与 fsync，前后宿主/容器字节一致；先保留原文件回执，验证解析无错误再显式 reload。
  不重启 PostgreSQL 或其他依赖。解析失败不得 reload；仅按已存准确原字节恢复本批文件并复核。
  reload 结果不确定时保留现场查实际规则和连接效果，不连续盲目 reload 或扩大规则。
- Account 运维身份只在受控检查中短暂 LOGIN；新运行候选始终 NOLOGIN。原生 account-policy-check
  使用准确非超级身份及固定制品，实证策略 SHARE NOWAIT 与已安装策略一致；用明确回滚事务持冲突锁验证拒绝。
  随后关闭运维 LOGIN，核验零残留会话。未启动运行候选时只能证明被禁止登录，成功登录待 c 的 enable 后验证。
- 实际核验 TLS 主机名/CA、错误密码、非 TLS、跨库、其他角色与旧 gateway 拒绝；原依赖连接和健康不受影响。
  维护工具无 public ports、只挂载自身 pgpass/公开 CA，连接准确 internal data network，不取得 DBA TCP 权限。
- 记录正式站点 HBA 前后摘要与生效证据，更新受控部署清单和恢复说明，避免后续部署恢复成旧白名单。
  精确清理本批短时工具/运维消费副本，不删除需保留的正式材料，独立审核并提交。

## 后续治理窗口与轮换约束

Token migrator 与 policy-operator 的短暂开启只属于后续 c；原生治理检查要求 migrator 具备
pg_read_all_stats，必须在 c 的设计中明确最小期授权、NOINHERIT/成员选项和退场撤销，不能在本项暗中授予。
显式 owner cap 仍由负责人决定，不使用测试默认值。

首次运行角色 enable 之前，必须确认剩余有效期、实际消费文件、治理 ACTIVE 与准确角色名单；过期或材料
不匹配立即停止。运行凭据轮换沿用受控维护、独立加密保管与新密码安装、逐消费者更新/重连验证和旧密码拒绝，
不能只延长 VALID UNTIL 或称当前程序会自动续签数据库密码。运行告警不能替代实际轮换执行。
