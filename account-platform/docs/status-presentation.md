# 账户平台状态展示合同

本合同对应 #1624 的状态枚举展示项。`pinvou3-app/src/features/account-platform/status-label.js` 只返回展示文本，不改写 API 响应、筛选值、命令、权限判断或恢复状态。原始 JSON、审计证据和协议标识仍保留原值。

## 语言与语义

词汇从 `pinvou3-app/src/shared/i18n.js` 的既有三语言词典及 `account-status-i18n.js` 取得。简体中文、英文、日文均提供对应文本。复用已有领域标签时，以该领域的语义为先；通用词汇只补其未覆盖的已知代码。

以下入口使用封闭的领域词典，不把其他领域的同名代码解释为本领域成功：

| 展示字段 | 依据 | 例子 |
| --- | --- | --- |
| 账户用户状态 | Account `000027_account_closure_saga.up.sql` 的用户约束 | `DELETED` 表示已注销；`BOOTSTRAP_PENDING` 表示等待初始化 |
| 付款订单状态 | Billing 付款订单及本地到期合同 | `PENDING` 表示待支付，不是审批完成；入账状态另列 |
| 审计导出状态 | Account `000032_audit_export_protection.up.sql` | `READY` 表示可下载；不表示已经下载 |
| 支付异常及晚到付款案件 | Billing 原案件状态及既有筛选合同 | 异常 `RESOLVED` 表示处置已记录，不据此宣称财务修复已完成；渠道事实不可见不表示未付款 |

审批、注册/资料修复、角色、用量、Token、价格和健康面板沿用各自已有领域标签，并补充通用状态词汇。价格派生状态仍由 Billing 的 `derivePriceLifecycleStatus` 产生；注册、角色和会话的状态转换、过期、重试与授权规则均不改变。

资料修复列表的当前 DTO 不提供注册阶段字段，页面继续不显示该项，不将其缺失解释成新的异常。付款订单展示兼容旧状态代码的读取；当前服务仍按现行迁移及各摘要字段表达退款与入账事实。

只接收文案对象的子组件使用该对象的 `statusLanguage` 展示语言元数据。元数据直接随对应三语言词典定义，避免全局语言可变状态、按翻译内容猜语言或在显示标签时复制业务状态；切换语言时随所选词典切换。

## 未知与异常值

- 查表只接受自有字符串标签，禁止从原型链取得 `constructor`、`toString` 等值。
- 未识别字符串显示本语言的“未知状态”和原代码预览，不映射成成功、失败或可重试，也不触发新请求。
- 预览最多读取 120 个 Unicode 码点。控制字符和方向控制符显示为转义文本；过长值标出省略。组件将结果作为 React 文本使用，不交给 HTML、URL 或命令解释器。
- 缺失及非字符串值显示本语言的“未提供状态”，不调用对象的 `toString`。上游客户端原有 DTO 校验及错误状态继续生效。
- 已有组织展示器的自有属性检查、三语语义及 React 文本回退继续保留；原始机器字段仍可用于诊断，不能据显示标签推断财务或授权终态。

## 验证边界

定向 Node 合同验证真实公布的用户和导出枚举、三语词典、同码不同领域、未知值及预览边界。浏览器回归从实际账户、管理员用户入口及真实 Token/角色组件验证语言切换、未知文本、筛选和命令保留原枚举。

浏览器使用共享 Vite/浏览器夹具和真实前端客户端，HTTP 与桌面原生 transport 在夹具边界受控替换；不代表运行真实 Account、Keycloak、数据库或安装桌面宿主。Portal 生产载体通过 `npm --prefix pinvou3-app run build:account-portal` 同步到嵌入静态目录；构建和夹具验证不能代替现场验收。
