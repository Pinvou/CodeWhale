# 桌面草稿的模型确认

普通桌面草稿显式选择 Account Platform 或本地模型后，首次实质操作仍只创建一次会话；模型绑定确认前不公布活动会话，也不消费草稿。确认期间的其他发送等待同一个创建结果，不绕过指定模型使用默认模型。

确认成功后才迁移草稿、工作区及已有模式意图。模型拒绝时保留当前草稿、模型选择和重试归属；多个等待发送的文本累计回填，避免同批界面更新只显示最后一条。空会话清理仍是尽力执行，不新增自动重试、资金恢复或模型替换策略。

真正的新导航或新的草稿模型选择使旧确认结果失去公布权限；等待期间改选工作区、项目或目录链时，也中止已按旧绑定创建的结果，保留新选择供下一次明确操作使用，不自动重建。旧结果不覆盖新选择，也不删除已被新导航接管的会话。未公布会话的失败不创建新草稿 epoch。定向测试执行真实 sessions/settings/chat 桥接工厂并控制 IPC 时序；它不是完整 Tauri、真实模型或支付验收。
