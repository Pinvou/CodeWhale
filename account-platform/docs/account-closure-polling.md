# 个人注销进度读取

浏览器文档和所属Portal面板均可见、且仍有读取权限时，每15秒只读查询一次；手动、初始和后台读取共享同一有效代际的在途GET。确认窗口及提交期间暂停后台读取，开始确认或提交会中止并退役更早的读取，迟到结果不能覆盖确认或已返回的提交回执。读取不会创建注销申请或改变原UNKNOWN主体、key和facts。

隐藏文档或离开Portal账户面板时停止定时器并退役在途后台读取；重新可见时立即只读刷新。桌面底层传输可能不立即响应取消，已退役的旧传输不阻塞继任读取，其晚到回调也不能释放继任所有权。主体、client、会话代际、读取权限变化或卸载会退役旧读取；即使client代际变化尚未触发React重渲染，旧响应也不被采用。

收到COMPLETED/ANONYMIZED终态后停止自动读取。401/403立即停止；连续三次其他读取失败停止自动读取并显示原有查询失败提示。短暂的后台失败保留已校验的进度事实；失败预算用尽也保留这些事实，不把网络错误猜成注销业务终态。成功读取清零失败预算，现有“重新查询”按钮显式恢复读取；可见性变化不会恢复已因鉴权或失败预算退役的轮询。手动查询、明确确认/取消、近期认证和原key未知结果恢复仍走原入口。

实际组件回归经现有入口`npm --prefix pinvou3-app run test:account-platform-closure-ui`执行。轮询用例使用真实React组件、Portal面板、BFF及桌面JS客户端和浏览器原生可见性事件，保留真实15秒定时器；受控fetch或transport仅模拟服务端读取/回执，并故意延迟返回来验证继任和迟到围栏。它不等价真实Account/Keycloak部署或Tauri宿主验收。统一Portal生成仍使用`npm --prefix pinvou3-app run build:account-portal`，不手改压缩资源。
