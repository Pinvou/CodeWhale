# ADR-003：活动组织按会话保存

- 状态：Accepted
- 日期：2026-08-12

## 背景

同一用户可加入多个组织并在多个设备登录，请求必须始终能唯一确定资源与付款主体。

## 决策

每个会话的活动上下文只能是个人，或用户仍为有效成员的一个组织。不同会话可以激活不同组织。用户表中的最近组织只作为界面偏好，不参与授权。

切换时重新校验成员关系、更新会话和成员版本，并清空客户端旧上下文缓存。组织请求不得静默回退个人 Token 或个人钱包。

## 被拒绝方案

- 用户全局活动组织：多设备会互相覆盖。
- 每请求同时激活多个组织：资源和付款主体无法唯一确定。

## 影响与回滚

所有资源 API 必须携带可验证的会话上下文。若撤销组织权限，管理和财务操作立即回源，普通调用在 30 秒内失效。
