# ADR-005：Token 预占、结算和释放

- 状态：Accepted
- 日期：2026-08-12

## 背景

模型调用的最终用量只能在上游响应后得知，但调用前必须阻止余额不足和并发超扣。

## 决策

Token Gateway 调用模型前以请求最大费用向 Billing 预占；响应结束后按实际逐请求用量结算并释放差额。确定未产生用量的失败释放全部预占。缺失或不确定用量时保留 Hold 并进入核对，不能按零计费。

`usage_request_id` 全局唯一，Reserve、Commit 和 Release 都必须幂等。模型已执行而结算超时时只重试结算，不重试模型调用。

## 被拒绝方案

- 结束后再扣费：并发请求可能超扣。
- 预先一次性扣最大费用：用户会长期损失未使用额度。
- Token Gateway 维护独立余额：形成双事实源。

## 影响与回滚

Billing 故障时 Token 调用 fail closed。未来可引入短时预算租约优化吞吐，但最终仍由 Billing 账本结算。
