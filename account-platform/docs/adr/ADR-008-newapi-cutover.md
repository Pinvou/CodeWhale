# ADR-008：新旧 New API 隔离与切换

- 状态：Accepted
- 日期：2026-08-12

## 背景

现有生产 New API 在迁移完成前必须保持不变，新账号和新计费平面也不迁移旧数据。

## 决策

当前生产 New API 在整个新系统开发和验收期间保持不变。新 New API 独立部署、独立域名、网络、数据库、配置和凭据，使用全新账号数据，不迁移旧账号、余额或 Token，不做新旧双写。

新 New API 数据面只允许 Token Gateway 私网访问。完整验收后由 DNS/API Gateway 一次切换；失败时入口回到旧系统，但新 Billing 继续处理已发生的支付尾单。

## 被拒绝方案

- 原地升级旧 New API：影响现网且难以回滚。
- 迁移旧账号和余额：缺乏可靠映射与核账依据。
- 长期双写：容易形成账号和资金分叉。

## 影响与回滚

用户需要重新注册和配置 Token。切换前必须公告并演练；回滚不把新系统数据写回旧系统。
