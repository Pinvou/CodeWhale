# 可信时钟采样

生产服务继续要求至少三个成功的独立 NTP 源，以中位偏移驱动现有 250ms 告警和 1s readiness/新写入门禁；缓存和每次网络请求预算不变。

偏移按 [RFC 5905 第 8 节](https://www.rfc-editor.org/rfc/rfc5905.html#section-8) 的四时间戳公式 `((T2-T1)+(T3-T4))/2` 计算，扣除服务端接收与发送之间的处理时间。报文仍须匹配请求 origin、支持的版本、服务端模式、同步状态和非零接收/发送时间戳。

源报告的 root dispersion 按无符号 16.16 秒解码，超过 1s 的样本拒绝参与中位值。这个上限与本服务的 readiness 偏移上限对应；它不是完整 NTP peer selection/root distance 算法，也不证明网络对称性或来源真实性。质量不合格导致成功源少于三个时，沿用现有拒绝就绪行为。

回归使用本机 UDP 报文验证质量边界，用固定四时间戳验证已知处理延迟与正负偏移。真实三源网络、主机授时配置与生产偏差告警仍需部署验收。
