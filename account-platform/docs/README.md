## 术语

| 术语 | 含义 |
|---|---|
| 个人上下文 | 当前 OIDC Session 的活动上下文为个人，使用个人钱包和授权资源；用户级全局同步是后续目标。 |
| 组织上下文 | 当前 OIDC Session 激活一个已加入的有效组织，使用组织角色、路由和钱包；进行中的调用按开始快照结算。 |
| 目标组织 | 组织管理 API 显式提供的 `target_organization_id`；用于资源授权，不改变聊天和计费活动上下文。 |
| 展示积分 | 面向用户显示的额度单位；内部以整数 `microcredit` 记账。 |
| `microcredit` | 账本最小单位；当前 `10,000 microcredits = 1 展示积分`。 |
| Token Account | Gateway 中的模型访问账号及其路由元数据，不等同于用户的 OIDC 登录账号。 |
| 本地独立模型 | 用户在桌面直接配置的本地或第三方云模型，不经过账号平台、平台钱包或 Token Gateway，不属于个人中心 Token Account 管理。 |
| New API | 独立的模型数据面，负责调用真实模型供应商并提供请求/用量证据。 |
| 平台托管路由 | 用户首次调用时由 Gateway 幂等创建、普通用户不可修改的默认 Token Account、凭据和模型路由。 |
| Hold | 模型调用前按最大可能费用冻结的额度，最终按实际用量结算或释放。 |
| 目标计量单位 | 后续版本化计价维度，例如 `INPUT_TOKEN`、`OUTPUT_TOKEN`、`IMAGE`、`REQUEST`、`DOCUMENT`；当前仍使用固定 input/cached-input/output 三元组价格。 |
| 目标协议预占公式 | 后续每种协议发布的不可变公式；不是当前可配置接口，不能据目标“缺省为 0”改变现有预占算法。 |
| `PROVISIONING` | Identity 与 Account 已创建；当前登录后的 bootstrap 同步确保钱包并激活，异步钱包 Saga 是后续目标。 |
| `REPAIR_REQUIRED` | 后续钱包/路由修复状态目标，不能据此声称当前数据库与 API 已提供该闭环。 |
| `CATALOG_VISIBLE` | 后续独立目录的展示状态目标；现有授权模型列表不是完整版本化目录。 |
| `CONTEXT_ELIGIBLE` | 后续资格管线的状态目标；当前请求仍逐次核验上下文、权限和路由。 |
| `RESERVABLE` | 后续资格管线的状态目标；现有具体请求是否可预占仍以 Billing 原子创建 Hold 为准。 |
| 可调用提示 | 客户端基于最近状态显示的非权威提示；Gateway 每次请求都必须重新判断。 |
| 人工修复 | 外部事实已确认但自动流程无法安全入账时，由管理员审计后执行的一次性补偿。 |
