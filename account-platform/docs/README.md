## 术语

| 术语 | 含义 |
|---|---|
| 个人上下文 | 用户级全局活动上下文为个人，以用户本人身份使用个人钱包和个人授权资源；桌面与 Web 自动同步。 |
| 组织上下文 | 用户级全局活动上下文激活一个组织，以该组织的角色、Token 路由和组织钱包执行请求；进行中的调用按开始快照结算。 |
| 目标组织 | 组织管理 API 显式提供的 `target_organization_id`；用于资源授权，不改变聊天和计费活动上下文。 |
| 展示积分 | 面向用户显示的额度单位；内部以整数 `microcredit` 记账。 |
| `microcredit` | 账本最小单位；当前 `10,000 microcredits = 1 展示积分`。 |
| Token Account | Gateway 中的模型访问账号及其路由元数据，不等同于用户的 OIDC 登录账号。 |
| 本地独立模型 | 用户在桌面直接配置的本地或第三方云模型，不经过账号平台、平台钱包或 Token Gateway，不属于个人中心 Token Account 管理。 |
| New API | 独立的模型数据面，负责调用真实模型供应商并提供请求/用量证据。 |
| 平台托管路由 | 用户首次调用时由 Gateway 幂等创建、普通用户不可修改的默认 Token Account、凭据和模型路由。 |
| Hold | 模型调用前按最大可能费用冻结的额度，最终按实际用量结算或释放。 |
| 计量单位 | 版本化计价维度，例如 `INPUT_TOKEN`、`OUTPUT_TOKEN`、`IMAGE`、`REQUEST`、`DOCUMENT`；价格、预占和实际费用均固定单位版本。 |
| 协议预占公式 | 每种模型协议独立发布的不可变版本化公式，把请求参数和模型元数据转换为预占计量单位数量；缺省参数为 0。 |
| `PROVISIONING` | Identity 与 Account 已创建、账号可以登录和管理资料，但个人钱包仍在异步初始化；平台模型和充值暂不可用。 |
| `REPAIR_REQUIRED` | 钱包初始化超过 SLA 仍未完成，账号继续存在并允许登录/资料管理，同时进入运营修复队列。 |
| `CATALOG_VISIBLE` | 目录展示状态；不判断当前上下文、余额或具体请求预算。 |
| `CONTEXT_ELIGIBLE` | 当前聊天和计费上下文的权限、策略、协议和路由允许使用模型；不判断余额、权益、并发占用和具体请求预算。 |
| `RESERVABLE` | 针对具体请求预算，在创建 Hold 时实时计算并以 Hold 原子创建成功为准。 |
| 可调用提示 | 客户端基于最近状态显示的非权威提示；Gateway 每次请求都必须重新判断。 |
| 人工修复 | 外部事实已确认但自动流程无法安全入账时，由管理员审计后执行的一次性补偿。 |
