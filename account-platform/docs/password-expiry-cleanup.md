# 密码引用的过期清理

Identity 的密码引用、授权到引用的重放记录、注册操作绑定分别维护按到期时间排序的索引，标识和期限与对应 map 在原有互斥锁下同时登记。索引不保存密码或指纹；重放及派发状态更新不新增索引项，也不延长原期限。没有到期项时，现有清理入口只检查最早期限，不遍历全部存量；到期批次仍逐项清理，不承诺固定清理耗时。

现有合同保持：密码引用默认保留 15 分钟，容量默认 4096、最大 65536，容量耗尽不淘汰已接受的引用；操作绑定保留原始 48 小时，已派发或结果未知的操作不能据引用过期重新获得首次执行权。引用和操作绑定在当前时间严格晚于期限后删除；授权重放记录沿用当前时间达到期限即删除的边界，两者不合并成新规则。删除过期引用时仍清空原记录的密码和指纹。

清理仍由原有请求入口触发，没有新增定时任务、后台协程、Redis 或持久化格式；进程重启、Account 授权、公开注册 bootstrap、用途/来源绑定和未知结果恢复语义不变。索引只减少清理时的存量遍历，不限制整个操作回执集合的长期容量，也不替代全局准入策略。

定向基准包含存量引用读取、注册操作派发围栏及实际进程内公开预检路由的原引用重放。受控时钟和授权夹具用于隔离索引成本；本机结果不是真实 Account/Keycloak、生产流量或延迟 SLA 的验收。分配字节基准报告的是批次累计分配量，不是保留内存上限。
