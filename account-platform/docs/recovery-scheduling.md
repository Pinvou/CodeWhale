# 恢复任务调度

到期 Hold 的证据请求保留原5秒单项预算。即使该预算耗尽，已有独立、最多2秒的持久化阶段仍须记录原身份、未决状态和1分钟退避；不能仅凭 `RELEASED` 标签认定证据完成。新回归使用真实 PostgreSQL 耗尽证据预算，再以单项批次确认后续健康候选可以前进，保留原丢 ACK、取消及证明身份回归。

生产 PostgreSQL 用量对账 worker 在准备处理下一项时才领取其原45秒租约，每轮最多50个不同任务。已见任务在本轮后续查询中排除，避免仍立即可选的未决项重复占满同一轮；尚未开始的任务不预先消耗共享租期。

原批量领取 API 保持兼容；未实现逐项领取合同的存储适配器沿用旧批量行为。已有 attempt 比较保护继续约束延期和停止写回，旧 attempt 不能清除另一领取者的新租约。领取变化不重派模型请求、不改变24小时资金规则，也不替代原资金幂等与终态围栏。

回归用真实运行角色、公开迁移和真实 chat 入口创建原用量，barrier 固定第一项慢查询与第二 worker 重新领取的顺序，仅推进夹具时钟。断言旧 worker 不处理已属于新领取者的排队任务、不改变新调度或 Billing 全表事实；新持有者的已知用量提交及原结果重放继续成立。该证据不代表生产容量或所有并发交错已穷举。
