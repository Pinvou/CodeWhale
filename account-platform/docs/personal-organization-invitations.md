# 个人中心组织邀请修复

## 范围

个人中心此前只提供邮箱表单，而当前账号注册使用用户名和手机号。Account 已支持目标绑定邀请，本次接通该能力，不新增邮箱要求、不开放用户目录枚举，也不将邀请改为管理员直接强制入组。

- 默认通过登录用户名邀请，可选通过已验证的中国大陆手机号邀请；显示名称和用户编码不能代替用户名。
- 创建默认 MEMBER 邀请，沿用 72 小时有效期及服务端组织成员管理权限校验。
- 被邀请人从个人邀请入口查看并确认加入；读取和接受分别遵守个人邀请权限，与当前选择的组织无关。
- 邀请展示可选 `organization_name`，用于确认加入目标；它只描述已授权可见的邀请，不开放组织详情或成员目录。旧服务不返回名称时保留组织 ID 兼容显示。
- Web 和桌面使用相同邀请合同；已有邮箱 API/客户端字符串调用兼容，不删除历史邀请。

## 安全与异常状态

- 邀请创建不透露目标账号是否存在；页面不展示一次性令牌。
- 手机号未验证、目标不匹配、邀请已撤销或过期时，不得加入组织；目标不匹配继续使用不泄露存在性的错误。
- 显式幂等键绑定单次创建意图，失败不清空输入，不自动重复变更请求。
- 同一邀请重复接受由服务端幂等处理；已是成员时不得重复创建成员或叠加角色。
- 接受可能已在 Account 提交、但后续资源激活失败。应保留同一邀请引用供用户显式恢复，不能因待接受列表不再包含它就声称全流程成功。
- 未知结果的恢复记录仅含邀请 ID，按当前用户隔离于 `sessionStorage`，支持同一标签页刷新后恢复；不承诺关闭标签页、重启或跨设备恢复。存储受限时保留内存重试入口；退出登录清除当前账号恢复记录，不缓存手机号、令牌或组织详情。
- 本次不包含 admin 添加成员搜索 403 的独立修复，不包含治理任务 GSA-07。

## 回归验收

1. 无邮箱账号按用户名邀请、查看、接受后成为成员。
2. 未验证手机号不可查看/接受手机号邀请；验证后可接受。
3. 其他账号既看不到邀请，也不能通过邀请 ID 接受。
4. 重复接受、已存在成员、撤销、过期均保持原有安全语义。
5. 组织切换、刷新失败、权限不足和提交失败不泄露上一次账号或组织的数据。
6. 双客户端发送正确 target_type/target 与稳定幂等键；三语文案完整，构建与架构守卫通过。

按用户明确许可，本次在当前分支修复，暂不合并存在无关冲突的最新 main。
