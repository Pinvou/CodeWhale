# 定时任务的平台模型绑定

定时任务保存的 `model_id=builtin_account_platform` 标识平台运行载体，`model` 保存创建或明确编辑时选择的目录引用。运行时只克隆该载体并使用任务原引用；修改全局默认只影响新会话，不改任务、任务生成的会话或全局设置。普通本地配置仍核对稳定配置 ID 和原 wire model，配置删除、改名或无 ID 且不唯一时继续要求用户手动重选。

自动执行和未显式重选模型的手动继续均使用 profile 的冻结引用。EnginePool 在既有 pins 快照中构造仅内存、app 私有的 `scheduled_model_ref`，提供器不再用随后变化的会话选择或 Engine 协议别名替换它；手动继续时明确重选仍沿既有优先级生效。普通本地模型不进入此平台引用分支；平台自动执行若缺少冻结引用则拒绝调用。

载体解析成功不代表允许调用。原 Account Platform runtime provider 仍核对完整模型设施、当前认证/授权、当前发布目录、有效能力和显式运行协议，并按原代理与资金门禁执行。原模型下架、旧名称无法解析或协议缺失时继续拒绝，不按显示名猜测 UUID，不替换为最新全局默认。用户只能沿现有重选流程明确修复任务绑定。

本项不改变 personal 个人余额服务与 models 完整设施的边界，也不改变定时任务审批、取消、恢复、凭据或 CodeWhale 生命周期。窄测试覆盖真实默认 setter、持久 profile 往返和模型解析；隔离 native harness 的验证不能代替完整 Tauri 宿主、IdP 或真实收费模型的端到端验收。
