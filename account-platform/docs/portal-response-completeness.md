# Portal 普通响应完整性

普通代理 API 保留原 32 MiB 响应上限。Portal 在提交上游状态前确认响应体完整：超限返回 `502 UPSTREAM_RESPONSE_TOO_LARGE`，读取中断返回 `502 UPSTREAM_UNAVAILABLE`，不把前缀作为完整成功结果。已知超限长度提前拒绝；未知长度最多读取上限加一字节。完整响应保留原状态、响应体和既有允许转发的头；HEAD、204、304 不把表示内容的元数据当作实际下载体。

缓冲空间按请求受该上限约束，不表示全局并发容量已经验收。写出后发生短写或错误会中断 HTTP，不再尝试改写已提交状态。错误响应不代表上游写操作未执行，也不自动重发写操作；客户端仍须沿原幂等键和权威回执恢复。

精确匹配的审计一次性下载继续使用原独立流式契约，完整转发较大的加密 envelope、证明及下载元数据；商品材料原件也走原独立路径。此次不改变票据消费、下载租约、资金权限或历史事件合同。
