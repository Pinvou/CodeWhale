# 全局价格回退的依赖错误

管理端 `POST /admin/v1/pricing/{price_version_id}/transition` 在执行 `END / FALLBACK_GLOBAL` 时，需要当前 MODEL 价格对应的协议/公式绑定和有效全局价格。若历史或受损价格缺少该绑定，返回已有 `422 PRICE_MISSING`，整笔生命周期事务回滚，不结束原价格、不创建后继价格或写入成功回执。数据库查询故障仍返回原内部错误，不解释为缺少业务依赖。

正常创建草稿已经验证绑定，已发布绑定不可变；此处补齐防御错误分类，不表示正常应用流程可以删除绑定。权限与 AuditOnly 策略、价格选择、已确认回执重放和不可变保护保持。该响应只识别缺失依赖，不授权自动补绑定、重写价格或资金动作；需要核对原协议/公式发布事实。

回归使用公开迁移和受限 Billing 角色，显式构造受损历史输入，经过已注册 HTTP 路由验证缺失、无权限、数据库读取故障与恢复重试，并以正常草稿/发布生产者验证有效回退和原回执重放。身份与 Account 授权服务为受控依赖，不代替真实 IdP 或现场验收。
