# 管理门户的会话读取边界

`AdminPlatformClient` 仅在同一登录会话内共享相同 URL 的进行中 GET。
同 CSRF 的普通会话刷新保留共享读取；发现新登录、未认证会话或完成登出时，
清除共享读取并取消其传输，同时重置内存中的授权版本观察及审批控制。

读取在响应头到达和正文解析完成后都核对会话代际与取消状态。
旧传输即使忽略取消，也不能向新会话返回旧数据或更新新会话的授权版本；
旧请求清理也不能删除新会话已经建立的同 URL 读取。
并行的旧会话查询或登出回执不能恢复或清除已经发现的新登录。

单个调用者取消不会终止其他调用者仍在使用的共享读取；最后一个调用者
取消后，该读取不再复用。已派发写操作保留原回执及未知结果处理语义，
只阻止其旧响应头污染新会话的授权版本，不自动重发写操作。

回归入口为 `pinvou3-app/tests/account_platform_admin_read_session.test.mjs`，
使用真实客户端及受控 fetch 固定响应交错，不代表真实身份服务或浏览器端到端验收。
实际 Portal 交付产物通过 `npm --prefix pinvou3-app run build:account-portal` 生成。
