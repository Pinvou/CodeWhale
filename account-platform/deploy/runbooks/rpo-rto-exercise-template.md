## 必填验证

- [ ] 所有恢复均在新实例完成，原实例未被覆盖。
- [ ] Schema 迁移成功，四份只读审计 SQL 无未解释异常。
- [ ] 账本每个 Journal Entry 平衡，钱包快照和 Active Hold 可重算。
- [ ] 恢复点前后支付订单完成主动查询和渠道账单对账，无重复入账。
- [ ] Outbox 自动投递、Inbox 去重和聚合版本连续；死信均有处置结论。
- [ ] 过期 Hold 分批释放，已响应但待结算 Usage 未被错误释放。
- [ ] 登录、组织隔离、余额、充值查询和 Token 调用抽样通过。
- [ ] Trace、日志和指标不含明文凭据或高基数私人标签。
- [ ] 回滚演练保留支付尾单处理，未修改或双写旧 New API。
