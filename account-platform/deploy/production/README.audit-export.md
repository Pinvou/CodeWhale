# 审计导出运行接线

本功能使用既有 Account、Portal 和已授权管理身份，不增加服务或公共未认证入口。
Account 私有环境文件必须提供 `AUDIT_EXPORT_MASTER_KEY_BASE64`，值为恰好32字节密钥的严格标准Base64；错误或缺失会在启动时拒绝。文件与部署密钥仅在受控站点供应，不写入仓库、命令日志或示例。原始密钥解码缓冲在构造后清除；保留同一密钥直到既有任务的文件和解密授权完成或到期，不能用换密钥宣称旧任务已恢复。

Account 启动接入真实工作进程。管理权限为 `platform.audit.read`、`platform.audit.export`；未脱敏导出还要求真实、未过期的 `platform.audit.pii.export` 临时角色授权，不由默认超级管理员继承。绑定的期限和分配流程必须来自已交付的角色管理组件，不能通过直接数据库造授权。032原SQL字节保持不变；本阶段包装器固定Up/Down身份，并在同一回滚事务内检查所有PII角色绑定。已有绑定时拒绝删除该角色，保留完整账本与绑定。

Portal只开放精确审计读取、创建、查询和下载端点。一次性下载仅允许GET；HEAD拒绝且不消耗票据或删除载荷。`X-Pinvou-Download-Token`只转发至该导出的GET下载端点，其他路由剥离。理由至少10个Unicode字符且不超过500个Unicode字符。导出的加密信封上限500MiB，普通API响应上限仍为32MiB。既有TLS、SSO、CSRF、网关隔离和会话身份由前序已交付配置负责，不使用F18延后补接线。

创建结果不明时，页面保留同一过滤条件、原因、PII选择和幂等键；已签发但回包遗失的单次票据不能再次签发，页面显示刷新核验与创建另一导出的明确恢复路径。解密密钥仅在当前页面展示供操作者安全保存，不写日志、URL或浏览器持久存储。

使用既有统一 Compose 投放入口，在个人及已启用阶段的 overlays 之后追加 `compose.audit-export.yaml`。沿用个人配置的 Account 私有 `env_file` 提供上述密钥，并使用同源 F17 Account、迁移及带本次 canonical 静态资源的 Portal 镜像。启动时严格校验密钥，无密钥或非法密钥拒绝启动；不要在公开环境变量、命令参数或日志中传入密钥。

当前为已审 F16 全父上的 F17 私有组合候选，尚未部署。格式为 `PINVOU_AUDIT_ENVELOPE_V1` 加密信封（`.pae`），内部 CSV 使用 AES-256-GCM 与 HMAC-SHA-256；不是 XLSX，也不是明文 CSV。操作者安全保存页面展示的密钥，按信封协议解密并校验完整性后读取 CSV；密钥遗失不能通过重发票据恢复。现有自动化验证覆盖协议解密往返，未运行外部电子表格或另造解密产品。

当前必要编译、受控 HTTP/浏览器和规范资源验证在不可变作者记录中逐项列出。真实数据库租约交错/PII回滚仅继承既有独立证据，当前 PG opt-in 未配置，完整 E2E、真实 IdP、集群和 TLS 投放未执行；本说明不构成部署或发布通过。
