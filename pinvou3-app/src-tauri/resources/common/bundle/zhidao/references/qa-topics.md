# qa 办公知识主题清单（HR / 行政 / 财务 / IT）

以下四大类办公知识查询，用户是在**问问题**（想知道具体规则/流程/政策/如何操作），**不是在找文档**。必须用 `qa`，严禁用 `search`。

**⚠️ HR人力知识类查询特别说明**：当用户输入涉及以下HR相关主题时，用户是在**问问题**（想知道具体规则/流程/政策/如何操作），**不是在找文档**。必须用 `qa`，严禁用 `search`：

- **领航者文化**：核心价值观、行为准则、四个坚持、四个用心、三个必须、文化践行
- **绩效与考核**：PBC、季度/年度考核、自评、绩效申诉、升职调薪
- **薪酬福利**：发薪日、年终奖/14薪、补贴、五险一金、体检、商业保险
- **考勤与假期**：弹性打卡、假期类型、加班调休/加班费、出差/远程考勤
- **员工关系与入职离职**：入职流程、劳动合同、离职证明、转岗、组织架构查询
- **发展与任职**：职级序列(T/P/A)、晋升、任职资格、导师制、培训
- **制度与政策**：员工手册、违纪违规、荣誉奖项、公司政策
- **户口档案与证件**：户口落户、档案转移、工作居住证、人才认定、护照签证
- **综合查询与支持**：HR接口人、个人信息维护、内推奖金、常见问题

只有用户明确说"搜一下员工手册""找PBC相关的文档"等明确要找文档时才用 `search`。

**⚠️ 行政办公/园区生活类查询特别说明**：当用户输入涉及以下行政/园区相关主题时，用户是在**问问题**（想知道具体规则/流程/如何办理/在哪里），**不是在找文档**。必须用 `qa`，严禁用 `search`：

- **园区/地址**：园区地址、邮编、门岗、前台
- **物业/报修**：物业报修、保洁、空调电梯、门窗维修
- **门禁/卡证**：门禁权限、工卡补办、人脸识别
- **停车/车辆/充电**：停车位、车牌登记、充电桩
- **食堂/餐饮/超市**：食堂餐点、外部就餐、超市购物
- **快递/邮局**：快递收发、小邮局
- **会议室/场地**：会议室预约、会议系统、培训教室
- **接待/参观**：客户接待、参观预约、展厅讲解
- **差旅/协议资源**：协议酒店、携程商旅、差旅报销
- **体检**：体检预约、套餐报告
- **工位/物资**：工位申请、办公家具、便民物资
- **安全/监控**：禁烟区、消防通道、监控查询

只有用户明确说"搜一下物业管理制度""找差旅报销文档"等明确要找文档时才用 `search`。

**⚠️ 财务知识类查询特别说明**：当用户输入涉及以下财务相关主题时，用户是在**问问题**（想知道具体规则/流程/标准/如何操作），**不是在找文档**。必须用 `qa`，严禁用 `search`：

- **报销类**：报销流程、差旅报销、酒店报销、话费报销、费用报销、交通报销、餐费报销、招待费报销、培训费报销
- **发票类**：发票开具、发票抬头、增值税发票、电子发票、发票丢失补办
- **付款类**：对公打款、付款流程、付款审批、合同付款
- **预算与成本**：预算编制、成本中心、费用分摊、预算调整
- **费用标准**：差旅标准、住宿标准、餐饮标准、交通标准
- **报销规则**：贴票规则、报销截止时间、报销审批流、超标报销、跨期报销

只有用户明确说"搜一下报销制度文档""找财务相关的文档"等明确要找文档时才用 `search`。

**⚠️ IT办公/电脑知识类查询特别说明**：当用户输入涉及以下IT办公/电脑相关主题时，用户是在**问问题**（想知道如何操作/解决故障/配置方法），**不是在找文档**。必须用 `qa`，严禁用 `search`：

- **账号/身份/权限**：域账号、域密码、账号、密码、过期、重置、找回、解锁、复杂度、权限、授权、管理员、群组、通讯簿
- **邮箱/邮件/O365**：邮箱、邮件、Outlook、Office 365、O365、公共邮箱、公邮、群组邮箱、转发、规则、退信、存档、附件大小、收件人限制、乱码
- **办公软件**：Office、Excel、Word、PPT、PowerPoint、Visio、Project、宏、加载项、激活、安装
- **网络/接入/VPN/认证**：VPN、iNode、Portal、认证失败、连接失败、外网、无法上网、代理、透明代理、IToIP、H3C-Guest、WiFi/无线
- **终端/系统/驱动**：Windows、Win10、Win7、补丁更新、系统激活、蓝屏/黑屏、卡顿、C盘满、驱动、分区、摄像头、耳机外放
- **虚拟桌面/云桌面**：Workspace、云桌面、虚机、云主机、网关、黑屏、分辨率、花屏、脱域、信任关系失败
- **文件/共享/传输**：FTP、WinSCP、FileZilla、FTPS、permission denied、共享路径、网盘/存储类网站
- **会议/协作工具**：腾讯会议、Lync、Skype、企业微信、打卡、头像、登录不上、会议通知、屏幕共享

只有用户明确说"搜一下VPN配置文档""找Outlook使用手册"等明确要找文档时才用 `search`。
