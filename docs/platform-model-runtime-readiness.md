# 平台模型运行协议校验

模型可见、已发布或账户已登录，不代表客户端能调用该模型。目录还必须明确发布受支持的 `runtime_protocol`：`OPENAI_CHAT_V1` 或 `DEEPSEEK_V4_CHAT_V1`。

模型被设为默认、显式会话模型或替代分支模型前，前端与原生命令均检查该字段。缺失、空值或未知协议不能进入新的选择；已有绑定保留，运行时继续拒绝调用并返回稳定错误码 `account_platform_runtime_protocol_unavailable`。聊天界面同时识别旧版本的原始错误，使用中、英、日文提示管理员发布能力或用户切换模型。

这是模型能力发布问题，与用户 API Key 或账户登录不同。管理员应核对上游实际协议后，通过现有模型能力草稿和发布流程发布新的能力版本；客户端不得根据显示名称猜测协议，也不得改写已有能力版本。本 PR 不改账户登录、引导页或悬停样式，也不修改线上模型数据。代码测试未证明线上模型已经恢复调用。
