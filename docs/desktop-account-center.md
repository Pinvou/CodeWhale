# 桌面个人中心

桌面端的个人中心提供个人信息、工作身份切换、资料与安全入口、充值和退出登录。

- 登录、短信登录、注册和找回密码使用同一宽度的居中表单；标签位于输入框上方。
- 注册和找回密码使用独立标题及返回登录入口。短信验证码旁显示获取按钮，并说明获取验证码的前置条件。
- 个人信息默认显示用户名、脱敏手机号和账号状态。组织邀请与组织管理在 Web 个人中心处理。
- 充值页复用现有个人或组织充值流程及权限校验；个人充值保留未完成充值的继续付款、扫码支付、结果查询和到账刷新。
- 支付历史、权益明细、用量记录和账号注销不在桌面个人中心展开。用户在「个人信息」页点击标明浏览器行为的入口，通过现有会话交接能力打开 Web 个人中心；充值页不显示这个跳转入口。打开失败时保留可重试的错误提示。
- 充值页不加载个人权益明细，也不加载组织权益、额度分配或成员管理数据。为恢复未完成的个人充值，仍读取充值订单集合，但不展示历史订单。
- 弹层提供固定关闭按钮、Esc 关闭、Tab 焦点约束和关闭后的焦点恢复；背景控件在打开期间不可交互，付款及验证子弹窗保留自己的操作路径。
- 账号状态和待充值状态使用本地化文案，付款剩余时间使用倒计时；刷新入口标明作用范围，没有充值商品时给出刷新或前往 Web 的提示。

本次调整不改变模型接入引导的触发条件或账户认证协议，也不改变 Web 个人中心的信息架构。

回归验证：运行 `npm --prefix pinvou3-app run test:account-platform-desktop-ui`，其中桌面场景使用合成账户和支付数据，不执行真实购买或付款。浏览器测试须按 `CONTRIBUTING.md` 通过 `scripts/ci-fixture-process.py` 运行。

原生重新认证专项回归使用显式的受保护工作区测试宿主，继续验证原请求、身份和异步响应围栏；它不代表生产桌面个人中心仍提供注销入口。生产桌面视图由上述独立浏览器回归覆盖。
