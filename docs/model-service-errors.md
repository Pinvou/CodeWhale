# 模型服务错误展示

主对话、原生代码会话、子智能体记录及桌宠共用模型服务错误分类与脱敏。模型调用的余额、额度、鉴权、限流和网络等错误以简体中文、英文、日文展示；普通工具、TeamRelay、H3C/EIP 等连接器错误不因单独出现 HTTP 状态码就被归类为模型服务错误，原始文本兜底仍先脱敏。

可恢复错误显示重试提示；权威终态到达后更新同一错误提示。只有实际写入带错误的终态记录，才由时间线错误卡替代气泡；没有终态记录时保留可见提示。成功恢复后隐藏失效的重试提示，不同会话和回合不互相去重。权威 `turn_id`、会话隔离和已有任务生命周期保持不变。

Official 的 `builtin_llmapi` 保持只读。其无明确第三方来源的鉴权或额度错误引导重新登录、稍后重试、切换其他可用模型或联系管理员，不要求修改内建模型 API Key 或充值。会话模型优先于全局默认模型；历史错误中明确的供应商信息优先于当前模型，已保存的结构化错误保留原提示。原生代码会话只使用归属匹配的已加载原生控件模型，不使用聊天会话的模型、默认模型或有效配置；切换或加载中、后台会话均不借用其他会话的模型归属。

错误文本与技术详情仅用于已有错误展示路径，不新增遥测事件或上传字段，不上传原始错误。凭据先经 Rust 脱敏，再经过前端展示层脱敏；不改变已有受控埋点开关、事件分类和终态去重。

回归入口：`npm --prefix pinvou3-app run test:chat-error-isolation`、代码原生时间线与 DeepSeek 时间线测试，以及已有行为遥测、内建模型状态和 TeamRelay 桥接测试。


Official 平台模型的生命周期拒绝使用服务端固定的 409 状态与模型拒绝响应头；供应商返回的同名响应头会被网关剥离。客户端只把当前已接纳轮次、当前 transport incarnation 和 generation 的可信拒绝记录在原有 timing sidecar 的 `assistant_done.model_rejection` 中，不根据展示文案或供应商响应正文判断模型下架。认证成功且当前目录完整解码后，合法已绑定模型 UUID 缺失也只记录在 prepare 前捕获的同一 timing turn 中；鉴权、网络、无效目录和无效能力仍保留原错误分类。

普通聊天现有替代分支入口读取最新轮次的 `Failed` / `send_error` typed 标记，旧轮次失败、取消或后续轮次进行中不触发。分支仅绑定自身模型，保留原会话与全局默认。prepare 导致同步提交失败时会主动读取已落盘时间线；普通 `chat:done` 与代码原生车道的完成/提交失败同样读取现有权威时间线。读取只提交给原有 buffer/lane，删除重建、后续轮次或晚到的旧请求不能污染新状态。

代码原生车道仍沿用已有的会话模型选择控件与错误展示，本次不新增替代分支按钮，也不改变 Agent、权限、工作区或导航。timing sidecar 维持 best-effort：磁盘写入失败时保留原通用错误展示，不退回文本推断。

## 辅助会话选模边界

辅助会话继续继承主会话模型。桌面平台选模命令在读取目录、修改绑定或驱逐 Engine 前，复用现有辅助会话识别规则拒绝辅助目标；普通主会话的目录核验和模型绑定流程保持原样。

## 桌面模型代理的响应与读取边界

402 响应复用账户客户端已有的 2 MiB 完整读取上限。长度超限、分块累计超限或读取中断返回网关错误，不转发前缀或从不完整正文生成余额通知；此前已独立核验的可信响应头通知仍按原流程处理。读取保留已有的取消优先级，不改变调用身份、重试或资金事实。

代理模型目录的 GET 请求复用账户客户端已有的 30 秒请求预算，覆盖等待响应头和读取完整正文。聊天保留原取消及流式契约；网关的 2 小时上游预算不等于整个桌面操作或空闲读取时限，未新增聊天总超时策略。

管理员模型运行概览及其聚合回退的日期使用应用选择的简体中文、英文或日文格式，保留浏览器本地时区与原精度。个人用量日期格式保持原样；此处不扩大到所有管理列表或详情的日期策略。旧空平台模型绑定仍按原元数据恢复和清理规则处理，无法恢复时只记录固定原因及数量，不记录会话、模型、路径或原始内容。
