# A12 存活证据截止边界

Relay 的当前周期以 `min(last_liveness_a.at, last_liveness_b.at) + 30000` 为截止时间。双方必须在原截止之前提交有效的新序列心跳，才可延续连接的恢复资格；B 的心跳不能代替 A 的证据，反之亦然。

先前入口只校验角色、上下文与序列，依赖周期 `expire()` 清理。可控时钟复现：join=0，B 心跳=29000，时钟=31000 时恢复期限已无效，但迟到 A 心跳仍将期限变为 59000。默认清理间隔为 15 秒，不能充当逐消息的截止门禁。

本轮在所有存活消息的更新、证明签名与转发之前校验原截止。到期先同步撤销捕获的状态，再使用 `expectedLease` 精确终止原租约；异步清理不允许并发消息复活证据，也不删除回调安装的同 ID 新周期。清理失败仍不重新授予过期证据。恰好到期与到期之后采用相同的失败关闭边界。

已冻结的断线恢复预算保持原规则：第一次断线快照最后有效证据的截止，恢复期间不延长；这里修复的是断线之前的过期周期复活，不是另设恢复宽限期。

回归覆盖 A/B 双角色、截止瞬间、未运行清理 tick、所有存活消息类型、异步清理中的并发消息、同 ID 新周期、清理失败，以及实际 `ControllerRouter` 路由的拒绝与精确租约退出。正常长连接夹具在原截止前更新双方心跳，挑战历史过期测试同样先维持周期有效，避免以复活过期周期为前提。

共享 B 心跳夹具是父仓内 Rust 生产发送格式与 Relay 接收契约的跨端测试，依赖完整 monorepo checkout；不宣称复制 Relay 子目录即可独立运行整套宿主契约。

本文说明代码边界与测试范围；实际通过数量以当前提交的测试输出和 CI 为准，不代替双 Windows 真实部署验收。CodeWhale #97 合并依赖仍单独保留，本轮不修改底座 gitlink。

## A 端单次建连截止

专用 controller transport 每次建连使用固定 10 秒的单调绝对截止，覆盖请求构造、DNS、TCP、TLS 和 WebSocket upgrade，阶段进度不延长本次期限。Stop 优先于到期，到期优先于接纳连接结果；一次同步 poll 内跨过截止或触发 Stop 后返回的 socket 也直接丢弃。该机制依赖异步任务继续被调度，不承诺抢占同步阻塞或操作系统解析器内部工作。

尚未完成 upgrade 的尝试到期后，仅在 transport 内执行原指数退避并重试，保留尚未上 wire 的握手队列，不发送会结束 A 首次握手的 `Disconnected`。确定的快速建连错误和已连接 socket 的断开仍遵循原错误语义。首次连接的 40 秒总期限及已冻结的恢复证据截止保持不变；Stop、总期限失败及被替换操作不会因此取得新的恢复预算。

回归使用生产等待函数和真实 loopback WebSocket，覆盖升级挂起、退避、队列保留及 Stop。真实 A 端口回归组合 `run_controlling_connection`、生产 connector、验签夹具及真实 B 握手状态机，检查重试后安装租约并投影 Connected；Relay 网络端点与远端设备由测试夹具替代，不代表真实双设备或部署验收。退避权威信号、公平性和任务异常监督仍由 #1490 的其余验收追踪，本批不关闭父 issue。

## A 端主动断开收尾

主动断开在任何等待之前同步退役当前本地租约与业务密钥，并按会话意图 → 控制状态 → 业务通道的锁序提交原连接的会话意图、操作回执和 A 端下载索引清理。B 端捕获与发布仍由其独立生命周期管理。只有捕获的旧 socket 可以继续等待通知回执，两秒上限不变；等待被取消或尚未轮询的 flush 被丢弃时，也只停止该旧 socket。等待期间允许开始新连接，旧命令恢复后不再清理资源，发布断开状态前在控制状态锁内再次比较原尝试与完整状态；已被后继替代时只返回当前状态，不发布旧状态。重复断开没有旧 socket 时立即完成本地收尾。

操作等待者的清理同时核对本次登记的进程内身份。旧等待者被唤醒或超时后，不会移除复用相同请求 ID 的新登记。窗口每次打开也持有独立身份，设置面板和窗口的旧断开回调只关闭原窗口，Escape 后重新打开的窗口继续保留。主机 IPC 可控的实际挂载 UI 回归覆盖迟到成功、迟到失败以及同连接关闭后重开，原生回归覆盖旧等待者恢复执行后新连接的认证回执。

正常断开时，终态事件可以先于命令回包清空连接标识。窗口关闭按原打开身份完成收尾，界面忙碌和错误状态仍由各自操作守卫管理。回归同时覆盖设置面板与窗口在终态事件之后收到成功回包的正常关闭。原生组合安装后继 transport，验证旧收尾后仍可用、当前断开后确实停止，并完成下一次连接的租约安装。
