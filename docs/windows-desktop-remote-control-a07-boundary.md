# A07 审核后的适配边界

本文记录 A07 的阶段验收，不代表桌面双端远控已完成端到端接入或可以发布。
已发布的 Legacy WebUI v2 不受本波入口调整影响。

## 本波投影与私有内核

- 后端 Windows 能力标记统一投影为语义能力；加载前、非 Windows 和检测失败均关闭入口。
- 远控嵌套状态通过真实桥的读取与订阅投影，保持原有平铺消费契约。
- 任务发布序号独立于持久化准入序号；同一发布重投保持身份，不同状态转换有不同的有界事件 ID。
- 启动先持久收口旧任务，保留本次引导的收口证据；挂接 journal/清理钩子后消费并发布一次，
  不把历史终态重放成新的恢复事件。已派发但无法证明结果的任务仍报告 result_unknown。
- B 本地状态/取消的 IPC 投影使用 camelCase，与业务 wire 的 snake_case DTO 分开，
  取消确认与轮询使用同一完整租约投影；未认证业务 wire 仍未接入，不宣称 A 已收到远端状态。
- 上传和下载注入同一个计费注册表；私有传输内核校验有方向的 handle 和完整五元租约绑定。
  本波不开放 renderer 传输入口，也不通过持有管理器锁覆盖同步文件 I/O。
- 一个生命周期所有者处理任务终态、代际撤销和周期超时回收；撤销计费后仍保留准确暂存目标的清理权。
  清理失败占用有界目标槽位并在后续回收轮次重试，不记录宿主路径或密钥。
- 私有暂存实现位于功能内的 `controller/transfer/staging.rs`，宿主只注入会话隔离目录解析器。

## 刻意不暴露的入口

A07 没有认证业务 wire。已删除 renderer 的模型描述符/密钥包安装、
审批注册/Allow/Deny、持久/raw B history 的创建/读取/删除/离线标记及事件/快照写入入口，
以及任务提交/会话创建/切换三个准入入口、附件上传三个入口与产物下载/预览五个入口。
本地 B 的状态查看和停止操作、A 侧本地内存 controller history 创建/列表、
journal 读取及有界确认仍保留。native-only 的 controller live-context 只读入口仍注册，
当前没有剩余 renderer 写入/准入消费者；不得把它描述为已经删除。
能力快照原生命令仅读取 B 的本地库存；A07 不暴露把它错当 A 远端快照的 renderer 调用。
后续 A 侧快照必须经 Rust 认证传输收到 B 投影后，按 A 当前完整租约验证，不能借用本机 B 租约。
内部内核与生命周期状态仍保留，但不能把它们称为审批执行、模型导出、认证历史投影
或完整传输的完成实现。关闭传输入口同时阻止无消费者的已完成文件无限落盘；
内核当前完成后不持有完成收据与总字节配额，不能直接重新暴露。

A08 重新接入时必须逐项验证：

1. 模型凭据在 Rust 认证发送侧按 OS credential reference 解析为敏感类型；
   不能仅 refresh 后读取已清空的 preferences key，密钥不能跨 JS。
2. 审批必须来自认证 A 的完整租约/会话/任务/审批 ID，绑定实际 ACP session/tool call/option。
   使用接收侧的有界相对期限；记录请求、决策、派发和过期证据，
   不能把“记录 CAS 标记”当成操作已经执行。
3. 历史仅接受认证事件/快照。恢复持久计数、损坏文件 fail-closed、状态 reducer 与 revision
   以及总字节预算必须在重新开放前验证，不能由 renderer 自称“已认证”。
4. 任务和传输准入必须来自 Rust 认证的发送方，并绑定完整租约、会话、任务和请求；
   不得把 renderer 的 JSON 硬编码解释为 ControllerA。开放上传前必须有有界完成收据、
   完成文件总字节配额和真实任务消费者的原子认领/清理，覆盖终态、代际撤销、超时及清理失败重试。
5. 不得通过后续合并恢复旧的不可信入口；新入口应有真实认证路由回归，
   并相应更新 A07 的阶段入口防复活测试。

## 尚未覆盖的验收

本地独立 harness 编译真实任务、journal、传输、私有文件和周期回收模块，
但不代表完整 Tauri/CodeWhale 宿主编译、真实模型供应商调用或部署验收。
完整宿主检查由对应 CI 门禁验证，不能用 harness 替代。

既有非阻塞跟踪：endpoint egress #1389、订阅生命周期 #1390、
模型连接清理 #1391、模型完整绑定 #1392、重启暂存孤儿 #1393、
空 Cargo feature #1394、活跃传输绝对生命周期 #1401，以及同步文件 I/O #1426。
周期 inactivity 回收不等于解决绝对 TTL；关闭外部入口也不等于解决私有内核同步 I/O 延迟。
