# A07 审核后的适配边界

本文记录 A07 的阶段验收，不代表桌面双端远控已完成端到端接入或可以发布。
已发布的 Legacy WebUI v2 不受本波入口调整影响。

## 本波投影与私有内核

- 后端 Windows 能力标记统一投影为语义能力；加载前、非 Windows 和检测失败均关闭入口。
- 远控嵌套状态通过真实桥的读取与订阅投影，保持原有平铺消费契约。
- 任务发布序号独立于持久化准入序号；同一发布重投保持身份，不同状态转换有不同的有界事件 ID。
- 启动先持久收口旧任务，保留本次引导的收口证据；挂接 journal/清理钩子后消费并发布一次，
  不把历史终态重放成新的恢复事件。已派发但无法证明结果的任务仍报告 result_unknown。
- B 本地状态/取消的 IPC 投影使用 camelCase，与业务 wire 的 snake_case DTO 分开，
  取消确认与轮询使用同一完整租约投影；未认证业务 wire 仍未接入，不宣称 A 已收到远端状态。
- 上传和下载注入同一个计费注册表；私有传输内核校验有方向的 handle 和完整五元租约绑定。
  本波不开放 renderer 传输入口，也不通过持有管理器锁覆盖同步文件 I/O。
- 一个生命周期所有者处理任务终态、代际撤销和周期超时回收；撤销计费后仍保留准确暂存目标的清理权。
  清理失败占用有界目标槽位并在后续回收轮次重试，不记录宿主路径或密钥。
- 私有暂存实现位于功能内的 `controller/transfer/staging.rs`，宿主只注入会话隔离目录解析器。

## 刻意不暴露的入口

A07 没有认证业务 wire。已删除 renderer 的模型描述符/密钥包安装、
审批注册/Allow/Deny、持久/raw B history 的创建/读取/删除/离线标记及事件/快照写入入口，
以及任务提交/会话创建/切换三个准入入口、附件上传三个入口与产物下载/预览五个入口。
本地 B 的状态查看和停止操作、A 侧本地内存 controller history 创建/列表、
journal 读取及有界确认仍保留。native-only 的 controller live-context 只读入口仍注册，
当前没有剩余 renderer 写入/准入消费者；不得把它描述为已经删除。
能力快照原生命令仅读取 B 的本地库存；A07 不暴露把它错当 A 远端快照的 renderer 调用。
后续 A 侧快照必须经 Rust 认证传输收到 B 投影后，按 A 当前完整租约验证，不能借用本机 B 租约。
内部内核与生命周期状态仍保留，但不能把它们称为审批执行、模型导出、认证历史投影
或完整传输的完成实现。关闭传输入口同时阻止无消费者的已完成文件无限落盘；
内核当前完成后不持有完成收据与总字节配额，不能直接重新暴露。

A08 重新接入时必须逐项验证：

1. 模型凭据在 Rust 认证发送侧按 OS credential reference 解析为敏感类型；
   不能仅 refresh 后读取已清空的 preferences key，密钥不能跨 JS。
2. 审批必须来自认证 A 的完整租约/会话/任务/审批 ID，绑定实际 ACP session/tool call/option。
   使用接收侧的有界相对期限；记录请求、决策、派发和过期证据，
   不能把“记录 CAS 标记”当成操作已经执行。
3. 历史仅接受认证事件/快照。恢复持久计数、损坏文件 fail-closed、状态 reducer 与 revision
   以及总字节预算必须在重新开放前验证，不能由 renderer 自称“已认证”。
4. 任务和传输准入必须来自 Rust 认证的发送方，并绑定完整租约、会话、任务和请求；
   不得把 renderer 的 JSON 硬编码解释为 ControllerA。开放上传前必须有有界完成收据、
   完成文件总字节配额和真实任务消费者的原子认领/清理，覆盖终态、代际撤销、超时及清理失败重试。
5. 不得通过后续合并恢复旧的不可信入口；新入口应有真实认证路由回归，
   并相应更新 A07 的阶段入口防复活测试。

## 尚未覆盖的验收

### 启动降级与 IPC 合同（R15）

桌面域只有在持久任务恢复、history 恢复、所有状态与钩子装配完整成功后才发布
`DesktopRemoteReady`。平台能力投影同时要求平台支持和该就绪标记；未就绪命令的
状态参数经 `try_get` 返回固定 `desktop_remote_control_unavailable`，不构造空可写库。
非支持平台返回 `desktop_remote_control_unsupported`，不写桌面账本、不启动回收器；
Legacy Web 的恢复独立继续，损坏或不支持格式的原文件仍保留。

Tauri 2.11.5 自身的命令 `State::CommandArg` 已用 `try_get` 返回 `InvokeError`，
并不会调用 `StateManager::get` 的 panic 路径；本修复收口的是实际就绪能力和稳定错误合同，
不是宣称复现了不存在的命令参数 panic。真实 IPC mock-runtime 回归不等于启动真实 WebView。

A-local 内存历史列表严格使用 `RemoteHistoryEntry` 的 `status/bSessionReference`，
不冒用另一持久副本 DTO 的 `state/lastSequence/lastTerminalStatus`。
审批采用共享 controller 单调时钟，测试注入时钟仍保留。共享正文脱敏覆盖密码系键、
有效裸 Basic 凭据及敏感 HTTP header 的缩进续行；普通 Basic 描述、空行后普通文本保留。
后继 A08 的 unrestricted preview 固定脱敏强合同不能回退。

私有持久 history 仍有锁内整表复制与原子全文件重写的潜伏性能/容量风险；A07 没有装配
record 写入消费者，不能声称当前任务必然触发大文件重写。未重新开放该路径前必须完成
总字节预算、预读取边界、增量持久化及锁外 I/O 的所有权验证；不得仅因事件数量有界而当作字节有界。

本地独立 harness 编译真实任务、journal、传输、私有文件和周期回收模块，
但不代表完整 Tauri/CodeWhale 宿主编译、真实模型供应商调用或部署验收。
完整宿主检查由对应 CI 门禁验证，不能用 harness 替代。

既有非阻塞跟踪：endpoint egress #1389、订阅生命周期 #1390、
模型连接清理 #1391、模型完整绑定 #1392、重启暂存孤儿 #1393、
空 Cargo feature #1394、活跃传输绝对生命周期 #1401，以及同步文件 I/O #1426。
周期 inactivity 回收不等于解决绝对 TTL；关闭外部入口也不等于解决私有内核同步 I/O 延迟。

## 本轮新增审核的确认与收口

审核基线为 `0fcc8c9618b91b5b9633cb643ebdab98c6d78c1f`。
旧持久 history 内核的加载错误、重启 ID 复用以及 journal 包裹凭据过滤遗漏均成立；
但 A07 当前没有生产 create/append/apply history 消费者，也没有自由正文 journal/审批入口。
不得据此宣称已经发生用户数据覆写或线上凭据泄露。它们仍须在本层独立收口，
不能依赖后继 A08 的旧 history 退休掩盖当前分支缺口。

- 持久 history 构造显式返回错误，启动在发布远控状态前恢复；错误只关闭该桌面远控域，
  已发布 Legacy Web 继续初始化。缺文件才可创建新库；损坏、不可读或不支持的文件不被覆写。
- 未发布的私有 history 文件采用 v2，强制持久化 ID 高水位；删除最高项或删除全部后仍不复用 ID。
  高水位必须不低于已有 ID，溢出失败关闭；写入成功后才提交内存及计数。
  无计数的旧开发文件不隐式迁移、不清库、不自动重建，原字节保留；不增加开发期兼容路径。
- journal 与本层审批预览共用功能内的 bounded presentation-text 规则，处理引号/括号、
  Bearer、敏感键和值分离、Header/Cookie、宿主路径与 URL 敏感部分。
  这不是认证证明；后传时必须保留 A08 已采用的非空 unrestricted preview 固定脱敏强合同，
  不能用本层宽松正文过滤替代它。
- core 与真实 staging 共同执行 Windows 安全原文件名合同，资源分配前拒绝设备名
  （大小写、扩展名及 COM/LPT 上标别名）、ADS、非法字符、尾点/空白和长度越界。
  不静默改名或截断；合法 Unicode 文件名原样发布。对应既有跟进为 #1473。
- 附件回收使用 controller 的同一单调时钟；旧独立时基可使回收早或晚，不能泛称系统性偏晚。
  本轮只收口附件时基，#1403 的其余 owner/回收器整理仍未完成。
- journal 最大游标的比较不再溢出，序号耗尽不会先写入终态 CAS。
- 扩大 native ACP 验证发现既有源码探针在 Windows CRLF checkout 上无法定位 test module；
  只在测试内先统一换行，再保持原有精确生产边界切割与断言，并补 LF/CRLF 等价和不包含测试文本的对照。
  不更改 ACP 产品、运行时、CI 或任何跳过规则。

确认后暂缓的非阻塞项：能力快照同步扫描 P2 复用 #1549；平台启动门禁及桌面能力重算
P2 登记 #1648（重算子项须在 A08 UI 接线前闭合）；终态墓碑有界安全生命周期 P2 登记 #1649。
不得任意淘汰墓碑以获得容量；上述登记不表示已修复或可发布。

本轮回归直接覆盖生产 history 构造/持久化以及 journal 回放/快照链，
轻量 harness 不链接 history 所需的 CodeWhale 原子写入；history 证据来自另行运行的完整 native 测试。
本地 native 环境、通过数量、平台限制与尚未完成的 CI 以 PR 本轮修复回复为准，
不能将轻量 harness 或 GNU/LLVM 测试当作 MSVC、Linux 或真实双端部署验收。

## R15 原生 IPC 夹具的跨平台来源

启动失败/部分启动及原始 State 提取回归使用实际 mock 窗口的 `url()`，不固定
Windows 的 `http://tauri.localhost`。Tauri 在 Linux/macOS 的本地协议是
`tauri://localhost`；固定 HTTP 来源会先被远端 ACL 拒绝，使测试未抵达命令提取器。
保留完整错误码和真实 manager 断言，不放宽 ACL、不跳过非 Windows 测试。
本地 Windows 回执不能代替 Linux/macOS CI 的实际执行结果。

## 桌面事件订阅的停止边界（#1390）

每次 bridge 订阅持有独立的生命周期所有者。`stop()` 先退休所有者，再解除已登记监听；
注册 Promise 在停止或重建之后才返回的解除函数立即调用，不加入替代生命周期的列表。
旧监听已经排队的事件也不再修改替代生命周期的投影。这个边界只管理 renderer 监听，
不取消合法的业务在途回调，不重新派发旧代际任务，也不删除历史证据。

本次仅修复迟到监听释放；同一 Issue 中注册失败后的逐通道重试仍单独跟进。
使用实际 bridge 和可控延迟/拒绝 Promise 验证停止、重建、部分成功及重复停止，
不将这些单元回归视为真实双端部署验收。
