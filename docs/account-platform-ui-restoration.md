# 账户平台 Web 界面恢复

个人中心恢复“额度与用量”“订单与发票”“账号设置”分区；组织身份具备相应读取权限时增加“我的组织”。管理后台恢复工作台、身份与组织、资金与计费、模型与 Token、治理与安全五组导航。桌面宿主继续使用现有桌面界面与原生认证流程。

## 交互与业务边界

- 点击导航写入页面地址，浏览器前进、后退和详情链接恢复相应页面。旧个人中心和管理后台地址映射到当前分区；显式指向无权限页面时显示拒绝访问。
- 用户和组织目录具有详情入口。组织详情按概要、成员、组织单元、生命周期分区；成员搜索和分页使用服务端查询。修改、创建及删除使用现有确认和权限检查。
- 系统与安全嵌入管理后台时复用外层页面标题，不再重复标题；工作区独立使用时仍保留标题，工作台的紧凑健康摘要不受影响。
- 充值、财务审批和组织操作沿用当前业务控制器。切换导航保留已访问且仍获授权的操作实例；同一会话的价格管理入口共享未决操作。弹窗只在所属页面可见，隐藏页面的延迟读取不弹出跨页窗口；结果未知时只能恢复原请求，不能因切换页面重新分配幂等键或自动执行写操作。
- 个人资料通过字段弹窗编辑；组织删除继续要求停用、最新阻断检查、名称确认及二次确认。界面恢复不放宽这些限制。
- 管理员的组织操作在首次弹窗中展示组织名称及标识；单元操作同时展示单元名称及标识。无输入字段的操作不显示空字段框，删除单元和组织启停在首次弹窗与最终确认中保留影响说明。取消不发起写请求，结果未知时继续保留原幂等键与请求事实。
- 组织操作弹窗采用并排的取消和提交底栏；忙碌或结果未知时禁止取消已接受的请求，恢复原请求后仍可继续下一次操作。内联表单保持原有结构。
- 组织操作弹窗的字段组不叠加外框，字段按统一间距排列；保留原生字段组的禁用语义，输入控件自身边界不变。
- 后台组织操作使用一致的按钮层级：新增入口与普通提交使用主色，删除、移除、停用及所有权转让使用危险色；取消保持中性，最终确认按钮写明动作。个人中心与内联表单沿用原有样式。
- 组织改名入口和弹窗标题明确为“修改组织名称”，与单元改名区分；弹窗继续展示当前组织名称及标识。
- 成员行操作采用视口内的浮层菜单，展开不改变表格行高；关闭菜单保留操作实例，打开的确认或未知结果弹窗继续由原请求控制。菜单可通过 Escape 退出并返回触发项。
- 成员归属行显示单元名称或“未分配”，无归属范围的规则在列表表头集中说明一次。普通成员归属与单元管理员角色范围分别管理，显示简化不改变权限。
- 个人中心沿用原版充值卡片、按钮层级和间距；注销入口及确认按钮使用红色警告样式，查询状态与取消保持普通样式。确认弹窗挂载在页面根节点之外，同样保留警告色与键盘焦点提示。
- 财务四类运营概览恢复统计单位、快照或统计时段、纳入状态和相关记录跳转；只有确实应用了对应过滤条件的跳转才标记为筛选记录。钱包账目、应收、商品及支付复核目录的读取筛选使用现有服务契约。已退役的用量冻结管理读取接口没有恢复入口。
- 总览按服务独立加载，失败显示不可用；缺少字段不显示虚构的零值。金额以原有精确整数协议读取和显示。退款记录保留普通/强制退款两种操作身份。
- 模型菜单遵循会话返回的功能开关与当前权限。界面恢复不重新启用已退役的金融写接口，也不绕过审批和权限。
- 在线开票仍显示当前服务尚未提供的说明。

## 数据与发布

新增服务接口仅恢复管理总览、用户详情和组织详情读取，复用现有读取权限及 Portal 会话边界。它们不需要数据库迁移、数据重置或角色调整。新增 Token 总览代理继续使用现有管理查询来源签名；Billing 价格概览仅增加既有 GET 读取的精确转发。

部署时应核对实际运行版本及所需依赖，避免把与界面无关的服务升级或迁移混入发布。构建产物由 `npm --prefix pinvou3-app run build:account-portal` 生成并嵌入 Portal。

## 验证入口

`npm --prefix pinvou3-app run test:account-platform-restored-ui` 验证导航映射、真实组件入口的受控 HTTP 交互、失败恢复、三种语言、响应式布局及独立打包后的两个页面。受控 HTTP 用例不代替真实数据库或生产端到端验证。

该回归脚本在监听服务和运行检查的同一退出边界关闭共享夹具作用域。浏览器关闭失败时仍尝试关闭服务器，保留业务失败与全部关闭失败；未确认全部关闭时不删除夹具文件。

浏览器夹具对已退出的进程同样要求观察到关闭确认；退出码、信号码、断开连接或关闭回调返回都不能单独授权删除配置目录。

成员菜单的行高回归继续比较真实 DOMRect 高度，以固定 0.01 CSS 像素误差处理亚像素测量舍入，并拒绝非有限或非正高度；增长和缩小超过该范围仍失败。页面动画和浮层场景保留，纯测试覆盖已记录的舍入数对及超限变化反例，原失败记录不改写。

Account 的 `TestRestoredAdminReadsWithPublicMigrationsAndRuntimeActor` 使用公开迁移和实际非超级用户运行角色验证读取结果，并检查读取不新增审计或事件；必须使用专用的隔离 PostgreSQL 实例。

发布前还应运行受影响的个人、组织、财务、审批、认证回归及架构、国际化检查，并按仓库流程完成独立审核。生产验收使用只读检查，真实支付、退款和账户注销不能作为自动冒烟动作。

构建后运行 `npm --prefix pinvou3-app run audit:compat -- --portal-only`，校验三个 Portal 入口、实际 JS/CSS、内联脚本和本地引用；默认完整兼容审计也包含 Portal。兼容下限沿用项目 Safari 14，带 CSS 变量的固定定位使用明确的物理边界。
