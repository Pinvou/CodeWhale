# 账号平台与 main 整合记录

## 范围与决策

本次将 main 的 `7b5edbd202ad1359a8c3367ae259a86d437726ff` 合入准备分支，保留账号平台已有业务能力，不代表向 main 推送或部署。

用户确认的互斥项：

- 内置模型统一使用账号平台。移除旧 `llmapi_hub` 运行时、独占界面、桥接接口、部署入口及测试；不保留回退开关。迁移旧配置所需的标识识别与幂等清理仍保留，普通本地/自定义模型不受影响。账号平台内部的上游服务适配不是旧客户端接入，不属于删除范围。
- 跟随 main 退役专用三省六部/专家团队工作流及底座专用协议；保留通用多智能体和团队接力。CodeWhale 对齐 main 的公开 r13 gitlink。

## 整合设计

- 会话存储采用 main 的分模块结构；账号平台模型绑定保留来源类型，目录模型 ID 与运行时载体 ID 不混用。替代模型分支保留来源记录，删除分支只清理该分支的关联记录。
- 会话创建保留 main 的单次在途请求与导航代数保护。异步模型选择不得覆盖已切换的会话或新草稿。
- 普通会话未选模型时保持拒绝发送；main 独立评测已固定的模型快照不依赖交互默认模型，仍经过运行时凭据准备。
- 独立评测与普通发送、定时运行、重发一样，在正式提交新回合前推进账号平台传输回合标识，避免不同评测回合复用同一计费关联标识。
- 模型选择器采用 main 的共享组件位置，兼容账号平台目录、本地模型与宿主显式模型绑定；设置页仅管理新会话默认值。
- 桌面三语词典沿用 main 的分语言加载结构，接入账号平台与管理后台文案，不恢复旧账号登录文案。独立 Portal 直接消费本领域完整三语词典，避免保存为英文/日文时同步读取尚未装载的桌面词典而白屏。
- 构建统一使用 `vite.config.mjs`，保留 main 的兼容性与资源约束，并接入账号门户稳定资源名及凭据接入部署检查。
- CLI 引用桌面核心的独立锁文件同步新增的 `axum` 和 `ring` 直接依赖；不变更其他锁定版本，`cargo metadata --locked --offline` 校验通过。
- 对齐 main 的 Safari 14 与静态检查要求：请求标识使用 Web Crypto 安全随机字节；稳定默认参数引用，补齐详情项 key，并移除旧接入遗留的空错误观察器。凭据安全与审批规则不变。
