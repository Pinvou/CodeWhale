# 远控产物下载与重试

Chat 任务发布产物时，将清单中的长度和 SHA-256 与复制结果核对，保存为匿名私有文件。索引持有该副本；后续任务改写或删除原文件不会改变历史产物。复制期间内容变化、磁盘写入失败或超出既有 32 MiB 单文件预算会拒绝发布，不发布部分结果。索引清理或进程结束时释放副本；原始输出不因下载清理被删除。Code 任务仍使用已有的私有产物复制与发布路径。

Work 聊天会话（包括被控端 Chat 任务）启动内置 PPT 连接器时，将当前会话的产物目录作为启动参数传入。PPT 在临时子目录生成，完成后才原子发布到会话目录，供被控端扫描登记并显示于主控端的远控产物列表。无法写入会话启动配置时，会话启动报错。会话产物目录不可用或经过目录链接重定向时，PPT 工具报告生成失败。此规则适用于内置 PPT 脚本的默认输出配置，自定义连接器及显式输出配置沿用各自行为。

复制候选先以不可见状态登记，全部复制完成后重新检查原任务冻结期限与取消状态，再一次性发布该准入的全部产物。检查失败会撤销候选并释放副本，不能仅抑制通知而留下可下载的迟到条目。主控界面为内容校验失败、数据不完整、大小超限、产物不可用和容量耗尽分别显示三语提示；未知私有错误仍只显示通用消息。

下载结束后，传输核心立即释放活动传输和字节额度，下载所有者保留末块响应，以处理响应丢失后的同句柄重试。回执同时绑定五元租约、会话、任务、产物和任务准入序号；校验仍经过当前发布索引，其他块、换代租约或已撤销准入不能读取回执。

活动下载与终态回执合计最多 256 项，在开始传输前预留槽位，满额拒绝新下载而不淘汰旧回执。每项最多保存一个 256 KiB 末块及有界元数据，末块总预算不超过 64 MiB。回执沿用有效 transfer TTL（默认 10 分钟，仅允许缩小），自完成起算，重试不续期。到期回收、精确绑定清理和断连会撤销回执；中断终态会清理当时已存在的回执。任务退休本身不主动撤销已完成回执，读取仍须通过当前准入和产物索引校验。

主控端完成长度与摘要校验后，调用现有下载清理接口释放回执。清理响应丢失不影响已经验证的本地 Blob；TTL 负责兜底。确定失败仍清理句柄，结果未知保留原身份供桥接层重试。传输内部文件名使用 Windows 安全名称，无法直接使用显示名时改用不含路径的产物 ID；显示名保持原样供保存界面使用。

本修复针对 #2407 下载链路中独立确认的 #1745、#1755 与 #1729 触发条件。缺少原始反馈环境，不能将这些反例称作原反馈的唯一根因。隔离生产模块测试和桥接测试不代替真实双机安装包验收。
