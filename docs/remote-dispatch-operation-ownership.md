# 远程操作的界面所有权

控制端 A 的 ChatView 远程重试、安全放弃、取消、权限处理、预览和下载共用一个界面操作槽。
槽由独立对象身份及完整派发身份持有；A 的派发身份包含本地会话、远端引用、连接、
控制端租约、lease epoch、relay epoch、generation 和能力修订。会话或租约/能力换代会退休旧界面操作，旧操作的 finally 只释放
自己的槽，不清除后继操作。上传的传输令牌与操作槽分别收尾，不能因为传输令牌
已经退休而留下永久 busy。组件卸载也会退休界面所有权。
能力修订变化还会退休旧上传进度和按钮占用，但保留稳定会话的草稿与附件；
迟到上传的收尾只清自己的传输状态，不能清除后继上传。

新任务的发送准备先从宿主读取能力缓存。快照缺失、已过期、版本不匹配或剩余
有效期不超过 5 秒时，先等待既有能力握手完成（含 B 的认证回包），再读取快照。
因此窗口闲置导致续期定时器延迟时，可在原会话续期后发送，无需重建会话。
这一步尚未 reserve，按稳定草稿所有者保留本次文本、技能、模型和附件选择；
会话、租约或 generation 改变则中止。续期后才冻结含能力修订的派发身份，
后续上传、commit 和迟到回执继续使用原有精确版本约束。失败不自动重放任务；
已准备、已尝试及结果未知的任务也不进入此续期派发路径。技能、模式、工作区
和模型仍由 Rust 使用新快照校验，已失效的选择不会被静默替换。
控制端的定时续期统一由桥接层管理；读取缓存按原到期时间调度，不延长有效期。
ChatView 不再同时维护另一套控制端续期定时器，旧租约/修订的定时器也不能续期
新上下文。界面刷新与发送准备对同一完整绑定的并发缓存读取共用一个在途请求，
避免互相取消投影应用。被控端本地能力投影的刷新仍独立保留。
后台续期不必经过界面的 preparing 状态；当前完整所有者和能力版本的新鲜投影
恢复后清除旧的读取失败提示。过期投影或迟到的旧所有者读取不能清除当前错误。

`node --test tests/remote_task_preflight.test.mjs` 覆盖过期、临界有效期、续期失败
及等待期间的所有者变化；组件 smoke 另覆盖闲置后勾选技能的实际发送路径。

被控端 B 的会话身份使用 generation 和 sessionId，不包含能力修订。
B 的能力绑定、到期和就绪校验另行控制发送准入，不能将其等同于 A 的操作身份键。

退休界面不等于撤回已经提交的远程任务。迟到的 commit 回执仍按原会话登记，
prepared/outcome_unknown 台账不因清理界面而删除、重发或改报成功。尚未完成上传
的旧重试不继续 commit。旧预览和错误不能写入新上下文；用户已发起的下载仍交付
原文件，但完成时不能清除新操作的 busy。

被控端能力未就绪时，发送入口保持关闭，显示对应语言的未就绪提示并保留草稿，
不把等待能力显示为消息可排队。能力就绪后可正常发送。本地附件数量、大小、
总量及名称/类型校验使用简体中文、英文和日文对应提示，未知故障仍使用有界
通用错误，不直接显示异常正文。

运行 `cd pinvou3-app` 后执行 `node tests/remote_dispatch_ownership_smoke.mjs`。
用例挂载真实 ChatView，实际运行 React 状态/副作用、重试处理器、传输 guard 和
派发 case helper；仅控制宿主桥的 Promise 返回。覆盖初次上传失败后的重试、
上传/commit 期间切会话、后继操作、租约/代际/能力修订变化、迟到预览、三语附件
校验和被控端能力就绪前后。该 smoke 已加入 frontend 完整选择集。

此处不声称验证真实 Rust IPC、双机部署或发布安全门槛，也不改变派发协议、授权
或持久化状态机。任务 handle 的协议兼容等无关行为不通过界面所有权修复改写。

`node --test tests/remote_file_transfer.test.mjs` 另对真实 validator 验证单文件
恰好 32 MiB、超出 1 byte，以及合法单文件组成的总量恰好 64 MiB、超出 1 byte。
该边界测试只提供 File 元数据，不读取大文件或证明真实上传；三语组件反馈仍由上述 smoke 覆盖。
