# 临时模型的完整租约绑定

临时模型包的内部绑定及 `temporary_model_package/v1.binding` 均要求
`connection_id`、`controller_lease_id`、`lease_epoch`、`relay_epoch`、
`remote_control_generation` 和 `task_id`。A 从当前租约构建；B 的协议入口核对包与任务信封，随后模型导入、凭据读取和运行时模型生成再次核对完整绑定。

任务终态清理从账本记录传递原任务的完整租约。迟到的旧任务清理不得移除同名任务标签下属于后继租约的模型。连接整体清空和应用关闭清空仍是明确的生命周期操作，不能作为普通任务的释放入口。

此功能尚未发布，不接受缺少新绑定字段的开发期旧包，不添加旧格式回退。Rust 与 JavaScript 协议校验、共享真实任务夹具和模型写方同步更新。此修复强化内部接口一致性，不声称此前可以绕过已有外层认证。

验证包含主/备模型既有合法包往返、所有租约分量不一致时的读取拒绝、旧终态回调不能清理后继包、正确终态释放及下一次正常安装，以及两端协议对缺失和陈旧字段的拒绝。应用原生 `temporary_model::tests`、`desktop_remote_model::tests`、任务清理测试与 Relay 协议测试须通过仓库生命周期边界执行。
