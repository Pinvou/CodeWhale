# 双端远程控制统计

远控沿用现有行为统计采集、授权、持久化 outbox 和删除机制，不增加采集地址，也不改变远控执行权限。

## 调用与主体

- 总调用 = 本地调用 + 去重后的远程调用。沿用现有任务口径：有明确执行终态的逻辑任务计一次，成功、失败、取消和中断分别统计；提交前拒绝和结果未知不作为已结束调用。
- A 发起、B 执行的任务归属 A。B 在共享会话主动发起的任务归属 B。模型来自哪一端不改变发起者归属。
- 两端只报告自己授权范围内的观测。任务标识使用随机任务 ID 的域隔离 SHA-256，不上传对端安装身份、配对码、地址、路径、提示词、文件名或凭证。模型只上报现有注册表分类。
- 服务端按匿名逻辑任务标识合并，事件 ID 按角色和阶段分别稳定生成。重连、重传、outbox 重试和 journal 重放不新增调用。真正创建新任务的重试使用新的逻辑标识。
- 只有 B 上报时，实际执行计入总调用，但标记为未归属，不将被动执行的 B 纳入用户活跃、激活、WSTA、WEVTA 或留存。A 的已认证结果接收可以在只有 A 上报时提供终态证据；没有证据时保留未知状态。
- 服务端删除某一端的数据后，从剩余授权事实重新计算，不从 B 的事件重建已删除的 A 身份。两端均未开启采集时没有统计记录。

## 事件与结果

在 `remote_control_event` 上增加可选的匿名任务关联、角色、模式、终态、耗时和注册表模型分类。旧的无关联远控事件保留为诊断，不反推历史调用数。

B 的任务 ledger 提供接纳和执行终态，通用引擎观察器提供开始、首输出和实际模型使用。执行结束不依赖 Relay 当前连接仍有效。工具调用沿用 B 的实际执行埋点，通过可选的 `execution_task_key` 关联逻辑任务并归属已授权的发起端；A 的镜像显示不再上报一次工具执行。

A 只有在已认证的 journal 或恢复快照结果成功投影到本地存储后报告接收，两个路径使用相同稳定标识去重；本地提交时保存原始采集授权，重启后继续沿用，关闭或删除统计会清除相关上下文。B 的执行上下文同样持久化，过期和损坏数据不会重建为新任务。上下文最多保留 30 天，各类最多 5,000 条，仅在本机存储，不上传原始任务 ID。

确定未越过发送屏障的提交失败报告为 `task_not_sent`，不进入提交数、等待终态或调用数；发送可能发生但结果未知的首次尝试报告为带 `unknown` 状态的提交，独立于等待中任务。后续实际接纳或终态可以解析该未知状态。B 在已认证入站请求被明确拒绝且未曾接纳时独立报告拒绝，A 关闭采集不影响 B 自己的拒绝诊断。

任务执行成功率独立于连接、权限、传输成功率，不再用所有步骤的成功事件占比代替任务成功率。权限缺失、权限变化、权限拒绝、超时、能力失效和模型不可用使用固定错误类别，不采集原始错误文本。

附件及产物只在整个传输完成或出错时上报；中间分块不作为一次完成传输。传输事件使用基于传输标识派生的稳定事件 ID，防止最终分块重发被重复统计。一次失败后恢复成功的传输可以同时留下失败和成功观测，不能将两者相加解释为文件数。传输延迟分桶测量最终操作的往返时间，不代表整个文件的传输耗时。

## 看板与边界

统计页新增独立的“远程控制”大项，支持今日、7 日、30 日独立切换，展示双端角色安装数、去重调用、任务模式、模型来源、结果分布、首输出与执行耗时，以及连接、重连、权限和传输诊断。沿用小样本百分比隐藏规则与主报表的每日贡献上限。

“未观测到主控接收”表示 B 有明确执行终态而未见 A 的接收事件，可能是 A 未开启采集、离线或回传异常，不能直接视为结果丢失。B 本地发起的共享任务不纳入主控等待接收的分母。执行耗时来自 B 的本地时钟；主控等待结果耗时来自 A 的本地时钟，不直接相减两端时钟。未知耗时保持缺失，不补成零。

主控等待结果耗时按接收事件所属日期采样，并遵守原始事件的每日贡献上限；接收覆盖率则以周期内经过每日贡献裁剪的执行终态任务为分母，与总调用统计共用每主体、每日最多 100 次终态的额度（含本地调用）。执行终态数、已接收数、未观测到接收数均基于这批任务，接收证据仍查询完整保留历史，允许跨日接收；被裁掉任务的接收不进入覆盖率。接收耗时采样与覆盖率的时间口径及裁剪对象不同。凭证自动续期时，仅将同一授权 generation 内的主控发起和被控执行上下文迁移到新采集周期并持久化；关闭统计、删除及重新同意产生的新授权不能接续旧任务。

发起者身份可关联时才进入用户活跃与留存。远控任务暂不推断场景、附件输入类型或用户显式价值行为；代理会话的复制、反馈、导出尚无完整绑定时，标记为显式价值不可关联，不进入 WEVTA 分母，避免把未观测误当作没有价值。

## 发布顺序与验证

先发布包含新 schema、聚合模块和页面的 Relay，再发布客户端。未升级的客户端仍提供旧诊断；新客户端对旧 Relay 的扩展事件可能被拒收，不影响业务执行，不能据此推算零调用。

验证覆盖双端同时上报、单端上报、B 本地发起、终态冲突、结果未知、提交拒绝、真实新任务、重复事件、跨日归属、删除主体、模型使用、每日贡献上限、上下文重启与过期，以及页面权限、周期切换、错误保留和旧服务兼容。上线后仍需用两台升级后的设备验证真实聊天、代码任务和断连恢复。
