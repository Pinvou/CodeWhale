# 未决远控操作身份

操作发送前，桥接层预留最多 128 个槽位，包含正在发送和结果未知的请求。相同租约、会话、任务及完整意图共享一次发送；容量满时拒绝新操作，仍允许已有未知操作用原 ID 对账。不静默逐出未知项，bridge stop 或同一窗口内重建也不清空。

原生 `DesktopRemoteActionState` 同时持有最多 128 个身份预约，键为规范化完整意图、会话归属、peer 和五元租约的 SHA-256；不在此缓存保存文件正文。因此 WebView 重载后即使传入新的候选 ID，同一未决意图仍使用原 wire request ID。完整意图包含 chunk 内容，而不只包含 chunk 索引和长度。相同租约的 resume 边界变化不生成新身份。

新的预约若在派发前失败会释放；派发后取消等待、超时或发送失败只能标记未知，不能证明被控端没有执行。原生预约使用独立 attempt token，迟到或已退休 owner 不能释放后来重试的槽位。只有当前关联的认证结果可以释放身份；`result_unknown` 保留。原生错误返回有界 `code`、实际 `requestId` 与 `authoritative`，界面据此区分本地失败与确定的远端结果。

附件 begin/chunk 继续使用既有未知结果围栏：未知附件不会自动重做，重载窗口也不能绕过原生围栏。附件 abort 仍可使用原 ID 对账清理。原生控制器确认切换或结束租约后退休旧代状态；JS 的旧代回调不能自动重试到新租约。身份不是磁盘账本；原生进程退出同时结束其内存中的控制连接，新进程须重新认证。

本修复不改变被控端去重/任务账本的既有契约，也不把本地主动放弃准备阶段任务当作未知远端副作用已消失的证明。容量耗尽必须先完成对账或结束原租约。
