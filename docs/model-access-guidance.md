# 桌面模型接入提示

模型接入状态同时读取账户身份、保存的模型、当前会话或草稿引用及实际生效配置。账户尚未确认、密钥库不可读、配置读取失败均不能视为“首次使用”或未登录。

- 只有没有活动会话、没有个人模型配置、没有具体平台模型选择，并完成身份检查的首次接入才显示欢迎层。欢迎层可通过“稍后设置”或 Escape 退出，设置入口始终可达。
- 已有会话保持可见。凭据缺失、凭据暂时不可读和账户检查失败使用不同提示；本地及配置完整的第三方模型不依赖品悟账户登录。
- 登录、短信登录、退出及窗口重新获得焦点会重新检查身份和当前模型。过期检查不能覆盖新身份；检查不会自动选模型、修改 API Key 或跳离当前会话。
- 已登录但没有选择具体模型时引导打开模型设置。内置平台承载记录本身不代表具体模型，也不需要用户 API Key。

模型状态协调器在首帧后加载，遵守现有启动体积门禁。欢迎层隔离背景焦点，嵌套验证码对话框拥有自己的 Tab 循环。远程受控对话使用其自身模型契约，不受本地接入提示影响。

验证：`npm --prefix pinvou3-app run test:api-key-gate`，以及在 `scripts/ci-fixture-process.py` 管理下运行 `test:model-access-ui` 和既有模型选择浏览器测试。夹具使用受控传输，不调用真实模型、不读取账户令牌；账户令牌及真实调用仍需在原生环境单独确认。
