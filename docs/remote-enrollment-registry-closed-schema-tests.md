# 登记库精确 schema 回归

登记库当前持久格式为 v3。回归从真实 StateStore 中完整有效、已授权的 v3 快照开始，分别只修改未来版本或只添加未知字段，通过真实 Registry open 和 Web/Desktop 授权入口验证精确错误分类。观察拒绝不得自动升级、回写、恢复备份或改变主备字节及修订。

测试覆盖的是登记库 namespace 的闭合集约束，不代替整个状态文件的未来格式保全、首次初始化恢复或文件权限资格。私有变异分别移除版本判断、精确字段判断时，两条对应回归必须在运行时失败；生产校验保持不变。

合法历史记录和在途回调保留，不清理旧 ID 或自动重新派发旧业务代际。本变更不增加兼容旁路。
