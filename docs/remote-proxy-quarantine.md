# RemoteProxy 容量恢复与不可逆只读隔离

活动文件损坏、超出加载预算或校验失败时，远控会话归档面板会显示有界原因。修复外部存储问题后可在原进程重新读取。也可先断开主控连接，再明确确认导出并隔离。此操作将完整原文件移到本机私有恢复目录，显示导出位置，并从空的活动台账继续。旧文件中的未决任务需要另行对账。现有只读归档和本地会话继续可用。

读取权限、未来版本或独立归档故障须先处理再重试。恢复操作与活动文件写入互斥，恢复前已打开的旧状态不能重新写回活动文件。对仍可读取但已达活动容量的记录，继续使用下方逐项归档流程。

活动 RemoteProxy 的未决请求上限是 64，永久请求身份预算是 4096。前者可在真实结果到达后释放；后者不会因重连或重启重置。达到永久预算或活动记录总量上限时，可在远程控制设置的历史管理面板处理旧记录。

先断开远程连接。没有未决请求的旧记录可以永久归档；仍有未决或结果未知请求时，选择“不可逆只读隔离”，阅读提示并逐次确认。取消确认不会修改记录。隔离永久保留当时的全部历史和未决事实，释放活动记录容量，并禁止旧会话、远程引用及请求身份再次执行。界面分别展示冻结的未尝试请求和结果未知请求数量，不再提供放弃、重发或恢复旧身份的操作。

隔离不会取消远端任务，也不会把未知结果改写成成功、失败或取消。远端任务可能继续，旧记录不会自动接收迟到结果。需要继续工作时建立新会话；不要把原任务当作失败后直接重复提交。

封存成功后若活动文件清理失败，界面会报告清理待完成；永久封存仍生效，下次写入或重启时恢复清理。若仅列表刷新失败，可手动刷新，无需再次隔离。存储无法读取或封存失败时保持原记录，先解决存储故障。

既有无未决请求的归档保持原格式。隔离采用版本化封套，旧版本程序无法读取该封套，因此产生隔离记录后不应直接降级；升级前保留完整受控备份，恢复时保持活动记录、归档数据库及封存锚点为同一快照，不单独回滚其中一个文件。
