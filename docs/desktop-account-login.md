# 桌面账号认证界面

登录、短信登录、注册和找回密码使用最大宽度 480px 的居中表单；窄窗口缩小外边距，超出窗口高度时在卡片内滚动。

- 字段标签统一置于输入框上方，输入框和主提交按钮等宽。
- 普通登录默认展示短信验证码，支持切换密码登录。勾选同意后，尚未注册的手机号在验证码验证成功时创建个人账号。新账号初始没有密码，可通过找回密码设置。
- 注册、找回密码提供各自的标题、说明和返回登录入口。修改首次注册选项后需重新获取验证码。已发起的注册可以沿原流程完成。
- 短信验证码与获取按钮组合展示；按钮不可用时说明填写手机号、获取验证码等前置条件。
- 中文、英文和日文分别提供完整文案；身份认证、滑块验证、短信和注册恢复仍沿用原流程。

运行 `npm --prefix pinvou3-app run test:account-platform-personal-ui` 验证认证行为及三种语言在桌面、窄窗口下的真实浏览器布局。按 `CONTRIBUTING.md` 使用 `scripts/ci-fixture-process.py` 执行浏览器测试。测试使用合成接口，不执行真实账号注册或发送短信。
